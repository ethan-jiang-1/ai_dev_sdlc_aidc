# Mike Krieger：洞察摘录

## 关键言辞

> “I don’t even worry about the Wi-Fi dropping out because if I set up the right context instructions—like a loop command—it’ll see things through.”

- 这是一个很强的信号：工作从“实时交互”转向“离线委托”。
- 人开始在交接上下功夫，而不是盯着每一步执行。

> “I’ll wish Claude a good night, set it off on a complex task, and wake up to find it’s done.”

- 这句几乎就是 Fable 时代工作节奏的缩影。
- 白天定义任务，夜里机器推进，早上人类做审阅和再定向。

> “The most impressive thing for me is just being able to delegate that kind of task and trust that the right thing will happen by the end.”

- 核心不是自动化，而是 `trust`。
- 一旦可信度足够高，任务分工结构就会变。

> “It really feels now like a teammate I can delegate a lot of work to.”

- 这里的重点不是“像助手”，而是“像队友”。
- 队友意味着它会补洞、继续推进、做局部判断，不是每一步都等指示。

## 结构性判断

- Mike 最有价值的地方，是他把 Fable 讲成了一种组织工具，而不是一个更好的 IDE 插件。
- 他反复把焦点放在 `verification` 上，这意味着强模型时代真正上升的不是编码门槛，而是验收门槛。
- 他描述的跨夜工作流也说明：以后很多“生产力”不再发生在你盯屏幕的那几个小时里。
