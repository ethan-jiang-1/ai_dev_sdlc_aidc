# Boris Cherny

- 身份：Anthropic，Claude Code 作者
- 角色定位：最接近一手观察 Fable 5 行为变化的人之一
- 为什么值得单列：他给出的不是泛泛赞美，而是对“模型如何工作”的工程级观察
- 核心贡献：把 Fable 的变化描述成从 `coding agent` 升级到 `thought and design partner`
- 最重要的判断：真正的新东西不是它更会写代码，而是它开始表现出判断力、品味、维度感，以及不靠提示词强塞出来的方法论
- 目录现状：现在已同时保留 Claude Code transcript 和 Fable 5 发布日原话整理

## 这人到底说了什么

- 他把 Fable 5 称为自 Opus 4.5 以来最大的模型跃迁。
- 他最看重的一点不是 benchmark，而是调试时会先测量、加日志、验证修复，再宣布完成。
- 他明确说过，这种调试习惯不是 Claude Code 提示词硬塞进去的，而是模型“个性”的一部分。
- 他还反复强调，Claude Code 的很多关键设计来自让模型直接用终端、直接用 bash，而不是给一堆精细封装的小工具。
- 在 2026-06-09 发布日，他还补了一层更操作化的判断：`less prompts and steers`、更高 token 效率、更长会话、更高 autonomy。

## 最值得记住的句子

> “With Fable, it's felt like Claude has stepped up from being a coding agent to a thought and design partner.”

> “It has judgment, taste, and dimensionality in a way that previous models didn't.”

> “There's nothing in claude code's prompting telling the model to do that, it's just part of its personality.”

## 我的判断

- 如果你的问题是“Fable 到底新在哪”，Boris 是必须先看的。
- 他提供的是行为层证据，不只是结果层赞叹。
- 他的材料尤其适合支撑一个判断：强模型时代，工作流设计会越来越像管理人，而不是调用工具函数。
- 现在这条目录已经不只是一个 Fable 观点摘录，而是开始同时覆盖产品哲学和模型行为变化。
