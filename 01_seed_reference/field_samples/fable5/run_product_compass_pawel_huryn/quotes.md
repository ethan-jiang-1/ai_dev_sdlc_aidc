# Paweł Huryn：洞察摘录

## 关键言辞

> “Fable 5 is the first model that's made me feel audited.”

- 这是 Paweł 最值得保留的一句。
- 它一下子把 Fable 和旧模型区分开了：旧模型更像 obedient worker，新模型开始像 reviewer。

> “I hadn’t asked for a review. It hit the contradiction and flagged it on its own.”

- 这句说明 Fable 的价值不止于执行任务，而是主动识别系统内部矛盾。

> “The row that matters isn't price. It's the thinking row: you lost the off switch.”

- 这是一个很好的迁移提醒。
- 它把“Fable 和旧模型的 API / workflow 差异”说得很具体。

> “Previous models followed my rules. This one evaluated them.”

- 这句是 Paweł 的核心判断。
- 它意味着更强模型不会再老老实实继承你为旧模型编的坏习惯。

> “A system maintained by model N tends to preserve the errors model N can't see.”

- 这句非常适合进入你的总方法论库。
- 它不只适用于 Fable，也适用于未来所有 agent knowledge layer。

## 总结判断

- Paweł 的价值在于：他把很多人只会隐约感觉到的“规则漂移”写清楚了。
- 对你要做的人物资料库来说，这类中腰部硬核作者非常应该保留。
