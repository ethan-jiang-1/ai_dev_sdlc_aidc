# Mike Krieger

- 身份：Anthropic，Labs 负责人；Instagram 联合创始人
- 角色定位：最适合解释“Fable 如何改变工作节奏和组织结构”的人
- 为什么值得单列：他不是从单次 demo 出发，而是从连续数月的真实使用出发，描述生产力和工程角色如何被改写
- 核心贡献：把 Fable 讲成一个能接住复杂任务、跨夜持续推进、逼迫人类把重点放到验证上的协作者
- 最重要的判断：更多工作开始在夜里发生，而人类的工作开始从“执行”转向“设方向、设标准、做验证”
- 目录现状：现在同时保留完整 transcript 和发布日 / Every 后续整理过的高浓度判断

## 这人到底说了什么

- 他明确说，自己会在睡前把复杂任务交代给 Fable，早上起来再看结果。
- 他提到 Fable 遇到远程服务故障时，会自己搭脚手架继续推进，而不是停在原地等人。
- 他认为这类模型模糊了 PM 和工程师之间的边界，因为不写代码的人也能把脑中的东西直接做出来。
- 他最重视的配套能力不是 prompting，而是 verification。
- 在发布日，他还把门槛说得更绝对：Fable 是第一个他敢“整包委托 whole projects”的模型。

## 最值得记住的句子

> “I don't even worry about the Wi-Fi dropping out.”

> “I’ll wish Claude a good night, set it off on a complex task, and wake up to find it’s done.”

> “It really feels now like a teammate I can delegate a lot of work to.”

## 我的判断

- Mike 的价值不在技巧，而在框架：他帮助我们理解“什么样的工作会迁移给模型”。
- 他最适合放在“组织 / 角色 / 工作节奏变化”这个维度里看。
- 如果你要判断 Fable 会不会真的改变团队结构，Mike 是最强的一手人物之一。
- 现在这条目录已经更像一个“工作节奏转移”的样本入口，而不只是一次访谈摘录。
