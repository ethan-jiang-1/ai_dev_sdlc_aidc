# Martin Musiol：洞察摘录

## 关键言辞

> “It takes problems whole.”

- 这句非常像 Bob/Joe 型人物会说出的真话。
- 它的意思不是“更聪明”，而是“不需要你把任务切碎了喂”。

> “It spends most of its time testing. Right call.”

- 这是 Martin 最值钱的一句之一。
- 很多人会嫌 Fable 慢，但 Martin 看到的是：它把时间花在了本该花的地方。

> “The security audit hurt.”

- 这句话之所以有力量，是因为它不是抽象表扬。
- 它指向的是那种真正让人难受的时刻：模型找到你自己签字放过的 bug。

> “Lean, clean, intuitive UI.”

- Martin 提到一个极简 prompt 就能触发很像资深产品设计师的 flow-level 反馈。
- 这说明 Fable 的价值不只在 coding，还在对整体体验的判断。

> “Pick the repo you trust most. Two prompts: a security audit, then ‘lean, clean, intuitive UI.’ One hour.”

- 这句把 Martin 从体验作者变成了可操作方法提供者。
- 它特别适合被保留，因为今晚就能照着试。

## 总结判断

- Martin 这种人物很适合被保留，因为他能给出“普通实战高手第一次被打疼时说出来的话”。
- 这些话比很多宏大判断更能说明模型到底改变了什么。
