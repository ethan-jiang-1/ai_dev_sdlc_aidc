# Thorsten Ball — "aim higher"：agent 派生 agent 的乐观极

> Amp（Sourcegraph）共同创造者，每周 newsletter *Register Spill* 作者。2026-09 的 #98/#99/#100 连续输出多智能体编排的一手操作实录——"agent 派生 agent 做黑盒测试"是当前"多代理协作"话语最生动的实践文本；他代表"人管方向、验证外包给机器证明"的乐观极。

## 当前立场小结（2026-10-03 建卡）

1. **验证外包给"机器证明"**："I want you to go and test this end-to-end, I don't care how, and **give me irrefutable proof that this works. Dazzle me. Give me a video as proof.**"（#99，09-12）
2. **多智能体编排的一手实录**："**Agents spawning other agents in orbs**, sending messages back and forth, eval'ing how agent-friendly the codebase is, **black-box testing features, black-box regression testing**…"——Amp 的 orbs / dial / steer 产品词汇同步定型（"Steer, Don't Queue"）。
3. **目标上移**："It feels like we've now entered a new phase… **we have to aim higher, we have to be more ambitious, we have to try it all.**"
