# 03_requirement_engineering — 需求与规格工程研究

**定位**：围绕 AI Coding 时代输入端意图形式化、可验证规格（Verifiable Specs）、契约体系与需求工程演进的长期学术与工业界研究沉淀。

与下游实践层 [`../../03_practice/requirements_engineering/`](../../03_practice/requirements_engineering/final/00-reading-guide.md) 及 [`../../03_practice/spec_driven_development/`](../../03_practice/spec_driven_development/README.md) 呼应。

## 核心关注

- **意图精确表达**：如何将人类自然语言意图无歧义转化为 Agent 与系统可执行的规格与测试。
- **可验证契约**：Spec 与 Test-first 如何成为保护代码资产不受模型幻觉破坏的物理防线。
- **演进路线**：从敏捷用户故事到 AI 时代的结构化 Spec 形式化表达。
