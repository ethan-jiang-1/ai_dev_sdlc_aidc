# stop_conditions — 停止条件三件骨架 · 按点深挖区

**定位**（2026-09-28 用户决定单开）：三件骨架的素材按**路别**组织（`raw/evidence-a/b/c/…`），
判读按**议题**组织（`digested/01/03/05…`）；想横向看"同一点上各家都怎么做、为什么"时，
信噪比太差。本目录把三个点各自抽成孙目录，**只装这三个点的做法与洞察——别的进来就是噪声**。

**命名**：`stop_conditions` 不沿用任何 KOL 词，是跨各家通用的描述性术语
（Anthropic 2024 原文即用 "stopping conditions"，见 [evidence-b](../raw/evidence-2026-09-26-b-stop-and-scheduling.md) §2）。

**三点是什么**（收敛判定权威在 [`../digested/03-构件.md`](../digested/03-构件.md) §一；此处只放一句指针版）：

| # | 点 | 一句话 |
|---|---|---|
| ① | [`01_machine_gates/`](01_machine_gates/README.md) | **机器可核判据做逐轮闸门**（测试/类型/lint/构建退出码）——可核性来自环境 ground truth |
| ② | [`02_hard_caps/`](02_hard_caps/README.md) | **硬性资源上限做兜底**（轮数/时间/拒绝计数/过期）——是资源熔断，不是质量分 |
| ③ | [`03_verdict_split/`](03_verdict_split/README.md) | **验收与干活分离**——完成判定权归谁是设计空间；干活模型自判＝最弱一极 |

三件同向，对抗同一个目标敌人：**提前宣告完成**（Anthropic 官方点名的长程 agent 头号失败模式）。

## 增长规则

| 增长事件 | 动作 | 不动什么 |
|---|---|---|
| 新做法（来源已有） | 对应点 `practices.md` 加条目，**必须自带核心片段**（原句/代码/参数，保留原文语言）＋机制展开＋`源` 行；只留指针不带货的条目无效 | 不改其他点的文件 |
| 新来源回源 | 先进 `../raw/evidence-<日期>-<路别>.md`，再回 practices.md 加条目；**实在取不到硬核内容的条目宁可放弃并记录**（转述级只进 insights 并标注） | practices 不收纯指针条目 |
| 新洞察 | 对应点 `insights.md` 追加（带来源指针） | — |
| 新待挖问题 | 对应点 README 的待挖清单加行 | — |
| 判定级结论（票数/强度变化、骨架被补强或推翻） | **回流 `../digested/03-构件.md`**（或按看板规则新开 NN 篇），本目录只留指针 | 不在本目录另立判定 |

**纪律**：每条做法标注强度（一手原文 / 厂商文档 / 源码 / 候选未复核 / 二手）；
候选未复核不进主张——沿主题铁律（`⏳ 待回源` 不进结论）。

## 挖掘的注意

三个点的素材在既有 evidence 档案里是**混装**的：同一篇原文常常同时覆盖三点
（例：Anthropic《Effective harnesses》既有 ①的 feature_list 逐条判定、又有 ②的过期兜底、
又有 ③的只许改 `passes` 字段）。从 evidence 抽条目进 practices 时**按点切片**，
**核心片段（最有意义的原句/代码/参数）随条目搬进来**——同一原文会在三个点里各留一条，
这不是重复，是切片；evidence 档案仍是全量逐字的唯一权威。
**自说明是硬要求（2026-09-28 用户定）**：只留指针不带货的条目无效；实在取不到核心片段的条目宁可放弃并记录放弃原因。
