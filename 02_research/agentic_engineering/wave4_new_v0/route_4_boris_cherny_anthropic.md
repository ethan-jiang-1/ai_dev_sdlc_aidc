# 叙事/线路：Claude Code 缔造者 - 激进卸载派

## 核心人物与工程哲学叙事
**KOL 级的路线对决 (横轴)：彻底解放双手的微型外包 CEO Boris Cherny**

### 1. 核心事实：彻底卸载 IDE 的男人
作为 Anthropic 下的一代明星工程产品 **Claude Code** 的缔造者和产品核心负责人，前 Meta 核心架构师 **Boris Cherny** 身体力行地展示了目前对于单一开发者最具颠覆性的“激进开发哲学”。

在这套哲学下，开发者不再是“修缮管道”的工人，而是转变为纯粹的发包人或“微型外包总裁”。
*   **激进实践的里程碑：** 他亲自示范了在长达数月乃至更长的高频开发时间里，**完全没有打开过任何传统的本地 IDE (Integrated Development Environment)**。
*   **只留一个终端：** 这不是开玩笑。所有的文件读写修改、命令行执行甚至 Git 版本控制等高复杂度的文件跳跃和逻辑推理，完全交由挂在终端后台运行的 `Claude Code` (底座为 Opus 及进阶模型) 全权主导。

### 2. 100% 的 AI 生成与恐怖的吞吐量
*   **生产力膨胀**：Cherny 在公开访谈中指出，基于这种 "微观外包 CEO" 视角，他现在的代码有 **100% 由 Claude 撰写**。
*   **PR 生成机**：在这种模式下，他曾在极短周期内疯狂合并了多达 **259 个 Pull Requests (PR)**，其中包含了大量的工程跨文件重构。代码对他而言，越来越像是一种快速流转验证意图并可随时废弃的中间形态。他仅仅负责给 Claude 提供包含完整上下文的敏捷开发 Ticket 看板和需求 Spec（规范意图）。目前 Claude Code 引发了内部高达 200% 的效能激增。

### 3. 在“跃迁4”叙事中的定调
在与 Michael Truell 的“务实控制派”对立的一面中，**Boris Cherny 代表着【彻底的激进卸载派】**。他认为对“底层代码清晰度”的不舍只是一种遗老思维。如果你有一支永远不会疲倦且极其熟悉上下文的“赛博发包联队”，那么手写代码的快感和逐行审阅的执念完全就是多此一举，未来的唯一工作只有精确控制 Spec 和验收。

> 数据与事件溯源：关于他完全卸载本地 IDE，纯靠 Claude 协助在短周期内推送并合并 259 次 Pull Requests 的工程哲学与效能数据，其目前**最权威的官方资料**出处，来自于 Anthropic 官方发布的技术访谈/演示视频 [Mastering Claude Code in 30 minutes with its creator, Boris Cherny](https://www.youtube.com/watch?v=6eBSHbLKuN0)，其中 Boris 亲自展示了他如何转变为“微观外包 CEO”的工作流。
