## Why This Matters

This source is directly relevant to the `DevEx -> AgentEx` tension in the seed. It captures how developers expect AI to change collaboration, performance measurement, and learning.

## Key Facts Captured

- GitHub found developers cared more about code quality and collaboration than output quantity as performance metrics.
- 81% of surveyed developers expected AI coding tools to increase collaboration within teams and organizations.
- The article highlights security reviews, planning, and pair programming as collaboration-heavy areas likely to expand with AI use.
- 57% of developers said AI tools help them improve coding language skills, and 41% said they may help prevent burnout.
- GitHub also warns that continuing to measure developers by code volume becomes less meaningful when AI changes code economics.

## Research Use

- Supports the claim that role value will shift toward higher-order work such as design, review, planning, and collaboration.
- Gives Topic 02 concrete evidence that performance metrics and team rituals must change as AI becomes routine.

## Caveats

- Survey was U.S.-based and focused on large enterprises.
- It reflects perceptions and expectations rather than a long-term longitudinal outcome study.
