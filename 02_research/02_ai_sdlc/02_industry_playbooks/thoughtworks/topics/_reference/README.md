# AI-Native SDLC Reference Library

本目录存放本轮 Deep Research 的 `Authoritative Copy`。每个重要来源单独成文，作为后续 topic 回填、artifact synthesis 和最终白皮书判断的本地证据本体。

## 读取顺序

- 先看 `_INDEX.md`：快速定位每个来源对应的 topic、用途和可信度。
- 再看 `00-shared-*`：这些是 Wave 0 共享地基，优先用于统一术语、风险框架、agent 架构和软件交付指标。
- Wave 1 开始后，每条研究线会新增 topic 专属 reference，并在 `_INDEX.md` 中归类。

## 写入规则

- 每个来源文件必须包含来源 URL、来源类型、证据等级、适用 topic、关键事实、可用判断和限制。
- 重要结论进入 topic seed 前，先在本目录拥有可追溯 reference。
- `_INDEX.md` 只做导航，不替代 reference 本体。
