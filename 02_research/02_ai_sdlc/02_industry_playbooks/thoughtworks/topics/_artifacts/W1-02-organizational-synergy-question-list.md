# W1-02 Organizational Synergy Question List

## Must Answer

- “中间循环”到底是新岗位、现有岗位重构，还是一种跨角色能力层？
- 哪些组织能力最能解释 AI adoption 成败：policy clarity、trust、platform quality、champion network，还是 executive sponsorship？
- 人机混编后，PM、Staff engineer、engineering manager、platform team 的边界会怎么重排？
- 如何避免把 Staff 工程师变成纯协调岗位，同时又不失去他们对系统摩擦的治理能力？
- AgentEx 是否真的会替代 DevEx，还是二者最终会合流为新的工作系统体验？
- 哪些指标最能衡量 AI adoption 的组织健康度，而不是只衡量个人产量？
- middle-loop operator 的最小控制台是否已经开始成形为 `graph context + agent library + automation builder + analytics + policy or admin boundary` 这样的组合？

## High-Value Follow-Ups

- middle-loop operator 的日常工具面到底长什么样：queue、policy, evals, routing, handoff, telemetry，还是 IDE 的增强形态？
- 哪些企业已经在正式招聘或定义 agent manager / AI workforce manager / AI specialist 类岗位？
- champion network 与正式管理链之间如何分工，才不会让 adoption 变成额外义务劳动？
- 当 agent automation 进入 admin-owned rule 和 permission inheritance 之后，middle loop 到底归 platform team、ops team、EM 体系，还是独立 AI enablement function 所有？

## Current Gaps

- middle-loop operator 的工具面证据已明显增强，但跨公司、非单一厂商的共识仍不足。
- 缺少更多失败案例来解释 champion network 或 executive support 为什么失效。
- 缺少更细的证据说明资深工程师如何在“写代码减少”后保持职业成就感与技术判断力。
