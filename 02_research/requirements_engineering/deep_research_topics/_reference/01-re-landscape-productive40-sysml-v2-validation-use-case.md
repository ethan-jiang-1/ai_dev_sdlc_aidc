## 关键事实

1. Productive4.0 官方 report 把 SysML v2 列为 OMG 标准化成就之一。
2. report 直接说明 SysML SST work led to a `validation use-case for SysML v2 in OMG`。
3. 该 validation use-case 聚焦：
   - service-oriented architecture
   - Arrowhead Framework
   - Productive4.0 Chemical use-case
4. HIOF suggested performing a validation use-case on service-oriented architecture in SysML v2，并被 SysML v2 consortium 接受。
5. 该 use case 不是抽象概念：
   - 从 Productive4.0 Norwegian use case 出发
   - 使用 Arrowhead Framework
   - 涉及 transport sensor data、TellU gateway、Unger local cloud、Prediktor analysis software 等 IIoT flow
6. report 明确说他们使用了 SysML v2 implementation prototype textual notation 的 alternative visualization strategy，并称为 `the very first real users`。
7. report 还说明该 validation use case 被纳入 SysML v2 public prototype release：
   - April 10, 2020
   - July 2020 upgrade
