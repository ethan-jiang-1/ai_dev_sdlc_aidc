# Harness 里头干啥 · 组织版（抓要害的讲法）

> 这是第二幕的核心讲法。目的：让组织决策者用一句话记住 harness 到底在干什么，以及**为什么它必须被集中建设**。
> 源：Böckeler 定义（`../_reference/rawdata_ai-coding-evolution-final/final_v4/03-2026-harness-era.md`）。
> 机制本身与 `-opc` 相同，落点换成组织。

## 一句话

**模型给能力，harness 给可靠性。** Harness = 模型之外的一切，它干的事是
**把一个"很强的模型"变成一个"可靠的交付"。**对组织，这句话的第二层是：**可靠性是唯一能被规模化、被审计、被治理的那一层**，
所以它才该被集中建成平台。

## 两套控制（Böckeler 的框架）

- **Guides（引导 / 前馈）**：在 agent 行动**前**约束它——"按这个样式写"、"必须过这个 lint"、"只能用这些工具"。
- **Sensors（感知 / 反馈）**：在 agent 行动**后**把结果喂回——"测试挂了"、"用户拒绝了这个 diff"、"exit code 非零"。
- 每套再分两档：
  - **computational（确定性）**：测试 / lint / 类型 / schema——可复现、可审计。
  - **inferential（概率性）**：AI review / LLM-as-judge——不可审计。
- **原则：能交给确定性的，绝不靠概率性的。** 组织要审计、要合规，这条是硬约束：门禁必须可复现、可留痕。

## 抓要害：三个动词 → 组织的三件"统一"

harness 里头干的事，归成三个动词；在组织里，它们各自对应一件必须"统一"的事：

1. **圈住（bound）** —— 沙箱 + 权限：让它只能碰该碰的文件、连该连的网、做被授权的操作。
   文件系统 + 网络双重隔离（bubblewrap / seatbelt）。→ **组织统一沙箱与权限模型**（谁、碰什么、问谁）。
2. **拦住（gate）** —— 工具协议 + 验证门禁：把"对错"变成机器可判的关卡，在错误离源头最近处就地拦下。
   授权要点：**authorize at execution, not at generation**（2026 CVE 的教训）。→ **组织统一工具协议与门禁**（准入 + 放行）。
3. **看清（see）** —— 可观测性 + provenance + CI：trace / metrics / logs 记下每一步，
   provenance 记下"产物谁造的、从哪来"，接进 CI 让每次交付可审计。→ **组织统一观测与审计**（还原事实 + 合规）。

## 六个构件（落到"装了什么"）→ 组织平台的六个"统一件"

| 构件 | 干什么 | 归到 | 组织读法 |
|---|---|---|---|
| 沙箱 | 文件 + 网络双重隔离 | 圈住 | 统一沙箱 |
| 权限模型 | 什么能做、什么先问；执行时授权 | 圈住 | 统一权限 / 授权 |
| 工具协议 | 模型能调什么工具、怎么执行、结果回哪 | 拦住 | 统一工具准入 |
| 验证门禁 | 测试 / lint / 类型 / schema，尽量确定性 | 拦住 | 统一门禁 |
| 可观测性 | trace / metrics / logs 还原 agent 决策 | 看清 | 统一观测 |
| provenance + CI | 产物可追溯、交付可审计 | 看清 | 统一审计 / 合规 |

## 为什么这一层在组织里必须被"集中建设"（承接第二幕）

- loop / graph 都站在它上面：loop 每次迭代实例化一个 harness；graph 每个 agent 节点跑在自己的 harness 里。
  如果 harness 各自为政，loop 会各自放大各自的错误，graph 会把不可靠的节点组织得更复杂。
- 三层本质是同一件事：**用反馈 + 确定性约束模型，换可靠结果**——harness 给单次反馈（Sensors），loop 把它连成循环，
  graph 把它编排起来。组织里，这三层的**责任归属不同**：harness 该集中（平台），loop / graph 该由治理定义编排与审计规则。
- 2026 安全事件集中爆发在这层——因为"可靠性"就住在这里，风险也住在这里。对组织，这里出问题的代价不是"一个人踩坑"，
  而是**供应链 / 授权 / 合规的组织级事故**。

## 与 `-opc` 的分野（一句话）

`-opc`：harness 是"个人要握住的 final say"；`-org`：harness 是"组织要集中建设的公共可靠性平台，final say 归治理"。
机制是同一套（圈住 / 拦住 / 看清），握机制的主体从"一个人"换成"治理层"。
