# 五层叠加故事线 · 组织读法（v0.5 · 引子的理论底）

> **v0.5 定位**：本文件是五层「引子」的理论底——它解释每个 SDLC 阶段的引子（Prompt/Context/Harness/Loop/Graph）从哪来、组织怎么读。
> 本页原 v0.1 的「五层 = 组织分工图」结论保留；整场 talk 的主线是「代码不再是瓶颈 → 把「怎么正确参与」外置成系统 → 沿六阶段落地」。

> 源：`../_reference/rawdata_ai-coding-evolution-final/final_v4.md`。本页是"五层叠加"作为**组织故事**的解读，
> 与 `-opc` 的 `05-five-layer-reading.md`（个人深度标尺）互补：同一台发动机，`-opc` 问"一个人能走多深"，
> `-org` 问"五层能力该在组织里建在哪、谁拥有"。

## 发动机没变，但问的问题变了

五层背后只有**一个**驱动机制：

> 模型越强，单次交互的边际工程收益越低，工程杠杆点就往上移。

`-opc` 把它读成"一个人的成长史 / 深度标尺"；`-org` 把它读成"组织里五种工程角色的**分工图**"。
四次换挡仍是同一种句式：

```
Prompt → Context：模型够强 → 不用把事实塞进 prompt
Context → Harness：环境受控 → 不用在 context 里写规则
Harness → Loop：运行受控 → 不用人决定"再来一次"
Loop → Graph：单 agent 够强 → 不用手动拆任务给谁
```

每一步"能力到位后，某个手工动作被上移/自动化"——在组织里，被上移的不只是"人的动作"，还有**责任的归属**。

## 从"人的身份"到"组织的岗位"

| 层 | 模型能力涨到 | 人的互动行为 | 组织读法：这层该建在哪 |
|---|---|---|---|
| Prompt | 能听懂指令 | 我写对那句话 | **任务层**：一线工程师的表达，放权给一线 |
| Context | 能记得更多、但会 context rot | 我挑它看什么 | **任务层**：组织知识被策展，放权给一线（配合统一知识库） |
| Harness | 能调工具、但乱跑有风险 | 我搭它运行的环境 | **平台层**：唯一该集中建设的可靠性边界 |
| Loop | 一次能做，但改一次就更好 | 我把结果反馈回去 | **治理层**：跨运行反馈，需防"更快放大错误" |
| Graph | 单 agent 乱发挥、不可审计 | 我编排多个 agent | **治理层**：多节点编排 + 门禁 = 组织级审计语言 |

人没有消失，人的**动作粒度变粗了**；组织也没有消失，组织的**责任归属往上移了**。
这正是本 talk 与 `-opc` 的分叉点：`-opc` 问"一个人何时应继续借、何时必须拥有改变运行边界的能力"，
`-org` 问"组织何时该把某层能力**集中**、何时该把 final say **收归治理**"。

## 它是"组织分工"的故事，不是时间线

1. **一个因，五个果**：听众只需记住"杠杆点上移"一句话，五层与五层对应的岗位都能自己推导。
2. **问题上爬了五层楼**：同一问题在爬楼梯——说 → 看 → 跑 → 反馈 → 编排；每一层答案不够用就往上挪一格。
3. **立场是"叠加而非替代"**：五层同时活着，组织**同时需要**五种角色，不能"上了 Graph 就砍掉 Harness 团队"。
4. **自带诚实的标尺**：成熟度向上递减，前三层成熟、后两层叙事期——组织重仓前三层，后两层观察即可。
5. **四个反转 = 四个记忆点**：
   - Loop ≠ 24/7 无人值守 → 可能错得更贵（blast radius 更大）
   - Graph ≠ 又一个 agent 框架 → 是编排范式（orchestration）
   - 五层 ≠ 年度替换 → 同一时间同时需要
   - 上升 ≠ 变简单 → 每一层都有自己的失败面

## 它和"组织"主题是同一件事的两面

最关键的翻译：这条故事线天然是一把**组织分工标尺**。五层不只是"领域注意力怎么走"，也能读成
**一个组织要把 AI Coding 建成怎样的分层能力**：

- **任务层（Prompt / Context）放权给一线** = 让懂业务的人写对那句话、挑对它看什么；组织不替他们包办。
- **平台层（Harness）集中建设** = 统一沙箱、权限、门禁、观测、provenance；这是规模化可靠性与审计的前提。
- **治理层（Loop / Graph）收归治理** = 编排规则、门禁、授权、审计、供应链准入由治理层定义；不交给个别团队自由发挥。

于是"组织要建成什么能力"这个主题，和五层故事线是**同一件事的两面**：
故事线给"路有哪几段、各归谁"，主题问"组织何时该集中、何时该放权、哪一层的 final say 不能外包"。
这大概率就是 talk 要把两者焊在一起的那个焊点。
