## 当前定调（未经变更不得漂移）

1. **主轴**：一个自称开发主力是 coding agent 的仓库，凭什么 fresh agent 进来不糊涂、不乱发挥？
   **命门 = 关键反转**：不赌聪明，赌成本结构（读对改对=阻力最小；读错改错=离源头最近的机器拒绝）。
2. **★ 弧线顺序（用户定，不许倒）**：**先把"为什么是那三条立场"讲清楚**（每条立场 = agent 的一个
   天然缺陷逼出来的），**再**走道（变更闭环／归属／决策记录／静与动／正确路径）→ 分水岭（十维评估＋
   垂直切片）→ 术（三巨头＋运行时）→ 分寸（立即借／有压力再借／不要照搬）。
3. **三条立场是全场滤镜**：机制页一律能回答"它在兑现哪条立场"，否则不许单独上。
4. **演示主线 = 一笔真实提交**：`5124a2a310` 逐环走（含红灯对照 2 红 95 绿）；道的五概念全在这笔变更上现过身。
5. **分寸页不许删**：讲优秀必须配"哪部分搬得走"；只秀不借就成发布会。
6. **证据纪律**：DSH 事实一律钉版 `46a7f68b09`（GitHub URL）；DSH 原话逐字英文＋紧跟中文；
   语料归纳与 DSH 原话不混标。
7. **本场红线本场自治**：DSH 是主角、允许点名上屏（与 101 相反）；不搬姊妹场任何禁用词／口径。
8. **不与姊妹场互为前提（已拍板：不提 101）**：开场不引用 101 词汇；"那一圈"／harness 在本场内部自己定义。
9. **七项拍板（2026-09-25，一问一答）**：① 页数 **30–38 设计、上限 50**；② 段二每立场配 **2–3 个失败形态**（讲厚）；
   ③ 道**五个概念全保留**；④ 标题**《解剖一只优秀的 harness》**；⑤ DSH 原话上屏**精选 5–8 句**（每段 0–1 句，其余口播）；
