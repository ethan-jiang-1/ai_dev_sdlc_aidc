> 相反；不套用任何姊妹场的禁用词表。

## 〇、听众（2026-09-25 用户定：宽口径）

**用 agent 写代码的人都算**——从日常重度用户到自建 harness／agent 平台的工程师与技术负责人。
痛点：知道 agent 时好时坏，想看"一套真正管用的 harness 长什么样"。
**不预设工程背景**：CI、schema、symlink、seam 这类词可以说，但**首次出现当场兑现成人话**（例：seam→"给整块能力换实现留的口子"）；术语是台阶不是门槛。

## 一、核心术语

| 词 | 定义 | 出处 |
|---|---|---|
| **DSH** | DeepSeek Harness，本场解剖的对象；开源仓库，钉版 `46a7f68b09`（`dsh-v0.1.7-rc.1`） | 语料 question.md |
| **三条立场** | DSH 的精华：① agent 是一等参与者；② 规则是可执行的代码；③ 每类事实有唯一的 owner（**上屏名：一个事实，一个家**） | 语料 answer.md |
| **糊涂** | 抓不住主线、读错、脑补——缺的是"必须遵守什么／系统由什么组成／为什么这样设计" | 语料 14 |
| **乱发挥** | 改错地方、绕过约束、自造设计——缺的是"改哪里／用什么流程／怎么证明做对" | 语料 14 |
| **七个信息缺口** | 上述六个＋"交付怎样算完整"；糊涂=缺口 1–3，乱发挥=缺口 4–6，交付=缺口 7 | 语料 14 |
| **关键反转** | 不赌"更聪明的 agent"，赌**成本结构**：读对改对=阻力最小的路，读错改错=离源头最近的机器拒绝 | 语料 answer.md／14 |
| **道 / 分水岭 / 术** | 语料三段式：道=五个概念（变更闭环／归属／决策记录／静与动／正确路径）；分水岭=从看懂到动手（十维评估＋垂直切片）；术=执行态机制 | 语料 answer.md |
| **三巨头（三条链）** | 入口链（agent 读什么）／执行链（agent 做什么）／反馈（做错了会不会被抓住）——三者咬合，每个动作被覆盖 | 语料 answer.md |
| **变更闭环** | 一笔变更从意图走到归位的流水线：意图→找 owner→有条件的决定→实现+文档+证据同一变更交付→本地检查→CI+语义 review→merge→知识归位 | 语料 01 |
| **归属（one home per fact）** | 每个事实住在负责它的那一层，其它地方只放 link 不复制 | 语料 02 |
| **决策记录** | 存"为什么"与取舍（含负知识：为什么不做 X）；状态目录 proposed/implemented/rejected/archived | 语料 03 |
| **静与动** | 四层分界：规则地图／配置／事实源／派生；越往下越活，只被上一层修改 | 语料 04 |
| **正确路径（paved road）** | Goal→Mechanism 归属表＋参与阶梯（L0–L3，按影响半径分层、不是价值排序）＋五问 | 语料 05 |
| **负例控制** | 新检查上线前先证明它会红：引入回归→看红→还原（"A guard only guards if the regression fails it"） | 语料 09 |
| **负知识** | "为什么不做 X"的记录；没有它，agent 把明确的缺席当遗漏，反复提已否决方案 | 语料 02/03 |

## 二、红线（v0.1 草案）

1. **DSH 允许点名上屏**——它就是主角；但一切 DSH 事实引用**钉版 commit `46a7f68b09`**（GitHub URL 可点开核对）。
2. **DSH 原话保留英文原文，紧跟一句中文转述——引文不硬译**；上屏**精选 5–8 句**（每段 0–1 句"定义级"原话），
   其余留在讲稿里口播（用户定，防引文墙）。
3. **弧线顺序不许倒**：三条立场的"为什么"先于一切机制展示；机制页不许脱离立场单独讲成奇观。
4. **分寸页不许删**：讲"优秀"必须配"立即借／有压力再借／不要照搬"——只秀不借就成发布会。
5. 不把 101／主线的禁用词、对象设定、页数口径搬到本场；反之亦然。
6. **数字口径（v1 起）**：DSH 内部数字可上屏（钉版证据的一部分）；**外部厂商数字一律不上屏**（要上须 ⚠️ 厂商自述＋观测日期，且只口播优先）。
7. **英文口径（v1 起）**：机制名与文件名＋精选 DSH 原话 7 句（03 页表已定清单）可上屏；**其余人的转述级引语（Karpathy／Chase／Stripe 等）只口播不进文案**——上屏前必须回源核原句。
8. **术语兑现**：门槛词（seam／事实源等）首次出现处，`[必上]` 里带一句人话兑现。
9. **序列纪律（2026-09-25 用户定）**：**任何一页不得引用后面页面才引入的概念**——听众一页一页往下读，
   向后引用自由，向前引用禁止；未讲过的概念、数字、清单不许点名（例：十维在 P20 才出现，B1 就不许说"十个维度"）。
10. **口播不进 04**：讲者材料与转述级引语（Karpathy／Chase／Stripe／Anthropic 等）一律放 03 的「讲法要点」列；
    `04_drafts` 里出现"（口播）"字样即违规——04 的每个字都是要呈现的。
