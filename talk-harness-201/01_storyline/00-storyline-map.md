## 主轴（全场只追一个问题）

**一个自称开发主力是 coding agent 的仓库，凭什么 fresh agent 进来不糊涂、不乱发挥？**

命门（answer 的一句话结论，也是收尾要回到的那句）：

> DSH 没有去训练「一个足够聪明、不会糊涂、不会乱发挥的 agent」；它把这句话反过来——
> **让「读对、改对」变成阻力最小的路径，让「读错、改错」在离错误源头最近的地方被机器拒绝。**

## 组织原则

- **弧线顺序（用户定，不许倒）**：先"为什么是那三条立场"→ 再道（五个概念）→ 分水岭（动手）→ 术（执行态）→ 分寸。
  三条立场是后面每个机制的公共根因——先立根因，机制才不是奇观清单。
- 每一段先给**失败形态**（agent 时代哪类失败逼出这道），再给 DSH 的应对，再给**可打开的实物**——
  这是语料自己的讲法（为什么要有这道 → 怎么应对 → 怎么落地），照搬。
- 演示主线：**一笔真实提交走全程**（`5124a2a310`，模型选择器显示 model ID，7 文件 +15/−14）——
  道的五概念在这笔变更上全部现过身；术的三条链是这笔变更背后的运行时。

## 六段脊柱

### 段一 · 开场：一句反常识的自述（认领）

- DSH 原话上屏：**"This codebase is developed primarily by coding agents."**
- 冲突感：coding agent 进大仓库的默认结局是两个——**糊涂**（抓不住主线／读错／脑补）与
  **乱发挥**（改错地方／绕过约束／自造设计）。DSH 却能"新来一个 agent 不靠带路，把一笔变更从意图走到归位"。
- 反转命题抛出（不赌聪明，赌成本结构）——先不解释，吊住。
- 认领：两个症状翻译成**七个信息缺口**（铁律／组成／为什么／改哪里／流程／证明／交付）——
  听众拿自己的仓库对号，哪个缺口答不上。
- 素材：answer「一句话结论」；14 全篇。

### 段二 · 精华：三条立场，每条都是被逼出来的（本场地基）

用户定调：**这段先讲清楚"为什么有这三点"，三条立场才立得住。** 每条 = agent 的一个天然缺陷 → 逼出的立场：

| 天然缺陷（为什么） | 逼出的立场 | 立场的内容 |
|---|---|---|
| agent 天然缺背景、会忘、会走捷径——而且开发主力**就是** agent | **① agent 是一等参与者** | 知识必须外置成可发现的入口（AGENTS.md、包 README、决策记录），不靠资深脑子与口口相传；写给 agent 读和写给人读是两种纪律 |
| prose 对 agent 没有约束力——写在贡献指南里靠自觉的规则，agent 不会当真 | **② 规则是可执行的代码** | 每条可机械规则接成 `exit non-zero` 的检查（gates／policy 脚本／CI）；原话："Agents follow enforced gates far more reliably than prose conventions" |
| agent 每次都是新来的——一处事实两个家，早晚分叉；口头传统对 agent 无效 | **③ 每类事实有唯一的 owner** | 意图归 Issue、理由归 Note、现状归源码/README、证据归测试、交付状态归 GitHub——一处一个权威，不重复不漂移 |

- 收束成**三层模型**（立场怎么组织成可借的形态）：变更闭环管时间／归属管事实去向／渐进披露管读取时机。
- 预告：后面所有机制都是这三条立场落到具体形状——**听众拿这三条当滤镜**，看每个机制时问"它在兑现哪条"。
- 素材：answer「三条立场」「三层模型」；02；03；14（关键反转）。

### 段三 · 道：五个概念（三条立场长成的骨架）

五个概念连续讲完，中间不插停顿页。每个概念一段固定讲法：失败形态 → DSH 应对 → 实物。

1. **变更闭环**——失败三形态：完成不可信／意图蒸发／知识散落。
   应对：一笔变更从"一段代码"升级为**完整交付物**（意图＋决定＋实现＋当前文档＋回归证据同 PR）。
   **演示页：commit `5124a2a310` 逐环走**（意图进入→三跳找 owner→豁免决定→7 文件同交付→
   **红灯对照：回滚实现保留测试，2 红 95 绿**→缺口如实标注→知识归位）——这笔变更是全场的演示主线。
2. **归属（one home per fact）**——失败：上下文有限／两处各写一版／人走知识走／现在与当初搅在一起。
   实物：根 AGENTS.md 每条 standing order 只有一到三行＋立刻跟链接；字数预算是**门禁不是建议**；
   `CLAUDE.md` 是 symlink（一条命令，两个宿主入口，零复制）；负知识也有家。
3. **决策记录**——失败：agent 没参与讨论／代码只答"现在"／口头传统无效。
   实物：状态目录即状态机（proposed/implemented/rejected/archived）；**两个对比例**（模型选择器
   局部修补→豁免不写；pnpm 竞态修复→再小十倍也必写，因为有持久取舍）；取代纪律：先吸收后删除。
4. **静与动**——失败：上下文每轮重组、状态跨轮存活，传统"静态=代码/动态=内存"的担保不存在了。
   实物：四层分界（规则地图／配置／事实源／派生）；**"Model-visible ⟺ logged"**——模型看到的
   一切可从会话日志重建，所以一次会话能整段回放。
5. **正确路径**——失败：在错误位置插代码／发明新接入方式／能用配置却动核心。
   实物：Goal→Mechanism 表（右边是**具体的注册 API**，不是"参考架构文档"）；L0–L3 参与阶梯
   （**不是价值排序**，只是影响半径）；新行为依次问五问。

- 素材：01–05（每篇的"为什么要有这道／怎么应对／怎么落地"三段照搬）。

### 段四 · 分水岭：从看懂到"我的项目怎么办"（顿悟页放这儿）

- **十维评估**（道五维＋术五维，每维三档：没有／有但不成体系／像回事）——打分只是自报，还要
  **垂直切片**：拿自己最近一笔真实变更走五问（结果是什么／owner 是谁／取舍记在哪／哪项证据会红／证据状态）。
- **"像回事"的验收**（全场最朴素也最硬的一句）：新来一个 agent（或人），不靠任何人带路，
  能把一笔普通变更从意图走到归位，并且每一步说得出来证据在哪。
- 这一段是从"看 DSH"切到"动自己仓库"的铰链——术的每一页都挂在它后面。
- 素材：06 Phase 1＋收尾。

### 段五 · 术：三条链咬合＋运行时（DSH 的执行态）

**三巨头**连续讲（三者咬合，agent 的每个动作都被覆盖）：

1. **入口链（agent 读什么）**——文件态：symlink 骨架／根文件只放 standing orders／子树文件"合适个数"；
   会话态：touch-driven 注入（触达才加载）＋ maxBytes 预算 ＋ 同内容去重；丢弃顺序：先丢宽的、保最具体的。
2. **执行链（agent 做什么）**——一个 tool-call 的完整管线；三个一眼要记住的设计：
   **call 先落日志再执行**／策略全在工具体之外（改策略只动一个文件）／结果只有一条权威出口
   （异常→isError，模型永远看不到"部分成功"）。
3. **反馈（做错了会被抓住）**——六层反馈各查各的（编译／加载／局部／组装／运行时关系／语义），
   绿一层不代表其它层绿；**负例控制**（"A guard only guards if the regression fails it"）；
   本地按 diff 选最小证据 vs CI 穷举——hook 不是小号 CI。

**运行时三面**（按需讲，可压缩）：

- **披露管线五层**：静态组织→按需注入→运行时组装（工具可见集按 scope 收缩）→溢出回收
  （compaction，绝不拆散 tool-call/result 配对）→隔离边界（subagent 不带父历史）。
  一句话：**"按需"的"需"由谁、在什么时刻、以什么预算决定**——这是写作纪律答不了的。
- **运行时查询**：三个查询面（dump 最终配置／生成 catalog／活运行时 inspect）；
  关键区别：catalog 答"声明了什么"，答不了"此刻跑着什么"——**源码只说明可能性，回答不了"现在"**。
- **Skills**：目录只给 name＋description（≤500 字符），选中才加载正文；摘要负责发现，正文才拥有指令。

- 素材：07–13（三巨头 07/08/09 为主，13/12/11 按页数预算压缩）。

### 段六 · 分寸与收尾（回到开场）

- **立即借／有压力再借／不要照搬**：立即借=入口链文件态＋one home＋决策记录＋负例控制的检查；
  有压力再借=Skills／生成 catalog／注入预算；**不要照搬**=插件全家桶／Project 与加权批准／双语 triplet
  ——它们是特定压力的产物，没有那个压力照搬就是负债。
- **四条边界**（贴墙级别）：可读≠简单／Skill≠enforcement／清理≠回滚／查询≠沙箱。
- **三问自检**带回家：知识外置了吗／正确入口明确吗／错误何时被发现——三问全绿，三条立场基本就位。
- 回到段一的反转收口：不要指望换一个更聪明的模型，要指望把成本结构反过来——
  **"让做对成为阻力最小的路"，这句话今天就可以在你仓库里开第一刀**（MVP 五件事）。
- 素材：answer「立即借／不照搬」「三问」；10；06 MVP。
