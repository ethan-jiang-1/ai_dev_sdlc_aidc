## 关键事实

1. 该 PDF 是 INCOSE MBSE wiki 上公开可取的 `SysML v2 Update` 演示稿。
2. 演示稿明确使用 `End User Organizations` 这一组别。
3. 该组别中可直接见到多个非 defense / non-government industrial organizations：
   - `Ford`
   - `General Motors`
   - `John Deere`
   - `Siemens`
4. 这些组织名称出现在 SysML v2 effort 的参与 / 关联组织清单中，说明 SysML v2 并不只停留在 defense 或 standards-body 自说自话的语境。
5. 这条 source 与 DoD guidance、Collins case、INCOSE automotive metadata 的区别在于：
   - 它给出的是更广的 non-defense organization set
   - 但仍主要是 participation / involvement signal
   - 不是 implementation outcome proof

## 核心内容摘录

### 为什么这条比单一 metadata 更进一步

- INCOSE automotive metadata 只能说明：
  - 有一个 commercial / industrial automotive case signal
- 这份 update deck 进一步说明：
  - SysML v2 的 end-user orbit 已经覆盖多个具名非 defense organizations

### 当前可稳妥支撑的边界

- 适合支撑：
  - `multi-org-non-defense-participation-supported`
  - `non-defense-industrial-interest-broadened`
- 不适合支撑：
  - 这些组织均已规模化生产落地 SysML v2
  - 广泛 industrial maturity 已经 fully proven
  - 任一公司的具体 implementation details

1. 这是官方 update deck，不是 adoption census，也不是 peer-reviewed industrial outcome study。
2. 它证明的是 organization-level participation / involvement signal，而不是 production implementation maturity。
