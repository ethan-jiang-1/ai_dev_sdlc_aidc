## 关键事实

1. Survey 名称为 `State of Prototyping: Spring 2026`。
2. 报告说明其目的覆盖 designers and builders across the design-to-code spectrum。
3. 样本规模：
   - 1,478 responses
   - 18 world regions
   - 61.4% respondents outside North America
4. 数据开放性：
   - full de-identified dataset available
   - license = CC BY 4.0
   - public API / MCP server available
5. 公司规模分布包括：
   - Startup 29.3%
   - Enterprise 17.7%
   - Mid-size 15.4%
   - Agency / Consulting 13.5%
6. Weekly tool usage 中 AI 工具已经进入 top 10：
   - Claude 50.8%
   - ChatGPT 48.2%
   - Claude Code 38.4%
   - Figma Make 34.8%
   - Gemini 32.3%
7. 关于 AI-generated code：
   - 43.8% spend more than half their building time on AI-generated code
   - 31.1% say most or nearly all of how they build is AI-generated
   - 37.7% do zero vibe coding
8. Role split：
   - Design Engineers: 80.9% spend 50%+ building time on AI-generated code
   - IC Designers: 35.0%
9. Production trust：
   - 32.8% trust AI output enough to ship with review
   - 1.4% report full trust without oversight
10. Workflow change：
   - 71.1% have added AI tools or made AI central in the last six months
   - 34.7% of enterprise respondents say AI is now central
11. Investment priorities：
   - 64.0% plan to invest in AI-generated coding
   - 46.3% in agent workflows
   - 40.2% in design systems & tokens

## 核心内容摘录

### 这条证据补的 gap

- 之前 Topic 04 multimodal / design-to-code 轴已有：
  - Figma Make official workflow signal
  - Vercel v0 workflow signal
  - Vercel/Stripe hosted customer outcome
  - Personagram independent design-study outcome
  - AI4UI enterprise-grade benchmark
- 但仍缺 independent adoption census。
- UX Tools 2026 survey 直接覆盖 design-to-code spectrum，并提供 open dataset，因此适合补 `independent-adoption-census-supported`。

### 不是 production deployment proof

- 这份 survey 报告的是 workflow adoption、weekly tool usage、AI-generated code share、production-with-review trust。
- 它没有逐一验证 respondent 的 production deployments。
- 因此它不能替代 named real deployment case，也不能证明 production maturity。

### 对最终报告的写法约束

- 可以写：
  - AI-assisted prototyping / design-to-code is now visible in an independent open survey.
  - Figma Make and Claude Code have meaningful weekly usage among designers/builders.
  - A substantial subgroup reports majority AI-generated building time and production-with-review trust.
- 不应写：
  - independent survey proves production deployments are reliable.
  - Figma Make / design-to-code is mainstream across all enterprises.
  - AI-generated code requires no review.
