## 关键事实

1. OMG 官方 `SysML v2 Tools` 页面明确说该列表覆盖 SysML v2 的：
   - authoring
   - analysis
   - integration
   - configuration management
   - transformation
   - visualization tools
2. 该页说明列表仅供信息参考，不代表 OMG endorsement，这一点有助于避免把工具页误写成认证名单。
3. 页面同时列出 commercial 和 open-source 工具生态，包括：
   - Ansys SAM
   - Dalus
   - CATIA Magic / No Magic
   - Intercax Syndeia
   - Model Driven Solutions / systemsmodeling.com
   - Obeo SysON
   - SysML v2 Pilot Implementation
   - OpenMBEE
   - PTC Modeler
   - Siemens Systems Modeler with SysMLv2
   - SysGit
   - Tom Sawyer Viewer
   - Violet Labs 等
4. OMG 页面把 `SysML v2 Pilot Implementation` 描述为 ongoing, open-source pilot implementation，支持 KerML / SysML v2 textual notations、visualization 和 API。
5. OpenMBEE 条目明确说明其 open-source collaborative platform 已被用于 NASA JPL、Boeing、ESO 等 large-scale complex projects。
6. 多个条目显式提到：
   - textual notation
   - graphical rendering/editing
   - standard SysML v2 API
   - requirements / verification / manufacturing / PLM / hardware/software integration
7. 这说明 SysML v2 已从“仅规范文本”进入“有公开工具清单、pilot implementation、open-source ecosystem、large-project platform usage”的阶段。

## 核心内容摘录

### 官方工具生态页

- OMG 工具页写明其目的是提供 SysML v2 tool vendors and tools 的信息列表。
- 列表覆盖的不只是建模编辑器，还包括 integration、analysis、versioning、visualization 等生态角色。

### Open-source / pilot support

- `SysML v2 Pilot Implementation` 被 OMG 官方描述为 ongoing open-source pilot implementation。
- OpenMBEE 则被描述为 open-source collaborative platform，并已用于 NASA JPL、Boeing、ESO 等复杂工程项目。

### 对 Topic 01 的意义

- SysML v2 现在不应只被写成“未来标准”或“纯概念模型层”。
- 更稳的写法是：
  - `official-positioning-supported`
  - `tool-ecosystem-supported`
  - `broad-industrial-adoption-maturity-pending`

## 风险与局限

1. 这是 OMG 官方工具生态页，不是第三方 adoption census。
2. 页内 vendor self-description 成分较高，因此适合支撑“工具生态已出现”，不适合单独支撑“市场成熟度已高”。
3. OpenMBEE 的 large-project usage 证明相关 MBSE/open model ecosystem 已有复杂项目场景，但不等同于“所有这些项目都已全面采用 SysML v2 final standard”。
