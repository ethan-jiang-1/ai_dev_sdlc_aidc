## 一、叙事检查（每次改稿逐条过）

1. **全场只有一条线**：P2 场景 → P3 症状 → P4 不在模型 → P5 在那一圈 → P6–P13 那一圈的五件事 →
   P14 搭多厚 → P15 归谁 → P16 合起来用 → P17–P19 收尾。每一页都是上一页的下一步。
2. **五件事与五种症状一一对应、同号同序**（看到 → 懂 → 会 → 走 → 验）。
   **任何一页讲不出对应的症状，就是零增量页。**
3. **编号三套已解耦**：症状／五件事 = `①②③④⑤`；四档 = 第 N 档；判据 = 那两句。**不许再混用圈码指四档。**
4. **`Agent = Model + Harness` 在 P5 给**（症状已在 P3 建立动机）；
   **`harness` 这个词全场只在 P5 与 P19 出现**（上屏标题亦不得含，见「题目」节）。
5. **五件事连续讲完**，中间不插停顿页（P6–P13；⑤ 拆两页但顺序不变）。
6. **P12 是全场支点**：把"代码"从技能门槛翻成**质量把关工具**；**P13 必须回答"那段检查谁写"**——
   不回答，这一页对技术一般的听众就落不了地。
7. **P4 必须回答"等下一代模型"这个反驳**——依据是 **Anthropic 官方原文（一手）**。
8. **四档压缩但不删**：它回答"这一圈归谁"，是听众对号入座的地方；**不许讲成"越复杂越高级"**。
9. **收尾必须收着讲**：P17「什么时候别折腾」不能省，否则本场就是劝人上自动化。
10. **本场原则上不引数字**：MAST 的频率只作底稿，不上屏；**P5 的 Top 30→Top 5 默认也不上屏**。
11. **术语按序入场（v6 起，取代原"零技术术语"）**：每个专业词走**三段式**（现象 → 命名 → 沿用），
    **一页最多命名一个新词**；清单见 `../CONTEXT.md` §2.4。
    **不是零术语场，也不是术语课**——听众应当带走 `harness`／上下文／代码／工作流／智能体 这几个词。
12. **上屏无行话**：过 `../CONTEXT.md` 第四节禁用词表，并过第四节末的"研发圈行话"清单
    （版本／字段／全局／传统代码／可靠性／一手 一类）。**基准读者见 `../CONTEXT.md` §〇**——业务熟、AI 有初步理解、技术一般、已经在搭 Agent 的人。
13. **英文只有 6 类**：核心公式／原文引句／`harness engineering`／P4·P5 署名原文／借词 `AI`／**`Agent`（仅两份手册，演讲件不出现）**。
14. **交付纪律**：内容件（`00-storyline-map.md`）只留内容与推导，
    **凡带 `[不上屏]` 的段落一律不进渲染**（约定见 `../CONTEXT.md` §七）。

## 三、说人话自检（写／改上屏文案时逐条过）

> 判据：**念出来像不像中国人说话**，以及**要不要解释一遍才懂**。**基准读者见 `../CONTEXT.md` §〇**。
> 出现下列任一条就打回重写。**但注意**：不是把术语铲光——术语按 `../CONTEXT.md` §2.4 的三段式引入。

| 毛病 | 反面例子（真出现过） | 已改成 |
|---|---|---|
| 被动句 | 让它**被验证** | 让它**经得起检查** |
| 「…的是…」句式 | 它翻出**的是**去年的模板 | 它**先翻了**去年的模板 |
| 抽象名词堆叠 | 每个**组件**都在替模型补… | 那一圈里的**每一块**，都是在替模型补… |
| 书面／翻译词 | AI 不能当最后的**对错判官** | "对不对"**不能由它说了算** |
| 生造名词 | 多一个**执行者**之前 | **多找一个人干活**之前 |
| 生硬动宾 | 你要做的是**用它** | 你要做的是**把它用起来** |
| 无标点的长定语 | 该看的它没看到 | **该看的，它没看到** |
| 抽象名词 | 模型只会**输出文字** | 模型只会**写给你看** |
| 直译术语 | **隐性知识**不写出来 | **脑子里的东西**不写下来 |
| **研发圈行话** | 拿到的是**旧版本** | 还在用**早先那份** |
| 同上 | **字段**有没有空 | **该填的**有没有空着 |
| 同上 | 一条线坏了**污染全局** | 一条线出了错，**全都跟着错** |
| 同上 | **传统代码**负责查 | **写好的程序**负责查，**当场命名为「代码」** |
| 同上 | 给**可靠性** | **管稳不稳** |
| 同上 | 证据**一手** | **官方原文** |
| 同上 | 反复**绕圈** | 来回**兜圈子** |
| 同上 | 该怎么**验**，没人管 | **做完谁来看对不对**，没人管 |
| **表单腔标签**（v17 补） | **你要摆清楚**：／**放清楚的标准**： | **摆什么**：／**怎么算摆清楚了**： |
| **单字加引号** | 第一件事就是"看" | 第一件事就是**看** |
| **指代不统一** | 哪一格 ／ 五格 ／ 哪一样 混着用 | 一律说「**哪个地方**」 |
| **缺虚词** | 全堆一个文件夹 | 全堆**在**一个文件夹**里** |
| **「是…的」判断句** | 第一轮不是用来做对的，是用来暴露…的 | 第一轮不是为了一次做对，是为了把…露出来 |
| **施动者错位** | 它一进来……**它**在哪儿？ | 它一进门……**我**在哪儿？（引它的心理话用第一人称） |
| **僵搭配** | 在这里 ／ 对它就等于不存在 ／ 得你先把话说到 | 在这儿 ／ 它就当没有 ／ 得你先把话说明白 |
| **连接词过文** | 并且 ／ 以及 | 也 ／ 再看 |
