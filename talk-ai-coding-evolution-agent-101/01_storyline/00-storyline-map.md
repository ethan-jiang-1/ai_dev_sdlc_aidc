## 题目

**上屏标题（候选，待定）**：

1. **Agent = Model + Harness：同一个模型，换一圈，就是两套系统**
2. 模型你只能选，外面那一圈你能搭
3. 它不糊涂，是因为外面那一圈搭对了

**副标题固定**：**搭对了，它跑起来就不糊涂。**

## 一句话主线

**Agent = Model + Harness。模型你只能选，选完大家都一样；真正决定它好不好用的，
是模型外面那一圈。那一圈搭对了，它跑起来就不糊涂——这门手艺叫 harness engineering。**

## 全场主轴：只追一个问题

> **同一个模型，为什么在别人手里好用，在你手里糊涂？**

**为什么是这个问题**：

1. **听众已经在被它折磨**——它忘了你说过的话、不懂你的业务还不问、反复绕圈、说做完了其实没做完。
2. **它把答案逼到唯一的地方**：不是模型不行（模型你也没法改），是**模型外面那一圈没搭**。
3. **它天然推出五件事**：那一圈要搭的，就是让它**看到什么 / 懂什么 / 会什么 / 怎么做 / 怎么验**。

> **术语约定（本文件全篇）**：`①②③④⑤` 指**症状与五件事**（一一对应、同号）；
> **四档一律写「第 N 档」**，不用圈码——避免三套编号撞车。

## 第二段：核心命题（为什么不在模型）

### 不是模型不行，也不是"等下一代就好了"

- 你**只能选**模型，选完就没法改了。同一个模型，在不同人手里表现不一样——
  所以差别不在模型，在**模型外面那一圈**。
- **一定会有人问：那等下一代模型不就行了？**
  模型变强，这一圈**会变，但不会消失**：**每一个组件都编码了一个"模型做不到"的假设**；
  模型学会了，那个组件就退休——**但新的天花板又要新的组件**。
- **落点**：**你等不到一个不需要搭这一圈的模型。**

> 依据：Osmani 2026-04-19（趋势级），"every component in a harness encodes an assumption about what the
> model can't do on its own"；同一篇的观察是 harness **不会缩小，只会移动**。见 `02_evidence/00-sources.md` §3。

### `Agent = Model + Harness`

> **"If you're not the model, you're the harness."** —— Viv Trivedy

- **模型**：给能力。你只能选，控制不了。
- **harness（模型外面那一圈）**：给可靠性。**你拥有它、你能搭它、它决定它跑起来糊不糊涂。**
- 一句话：**模型给智能，那一圈让智能真的能干活。**

**旁证（可上屏，标注来源）**：同一个模型，**只换 harness**，在一个公开基准上从 Top 30 进到 Top 5。
（⚠️ 厂商自述，**上屏只写 "Trivedy, 2026"**，不写公司名；本场只作方向性信号。）

**命名纪律**：`harness` 这个词**只在本段与收尾正名出现**；其余各页一律说「**模型外面那一圈**」。
理由与例外见 `../CONTEXT.md` 第二节 2.2。

## 第三段：那一圈要搭的五件事（本场主体）

> **五件事不是拍脑袋分的**：它们既对应 harness 的组件面（`../02_evidence/00-sources.md` §1），
> 也对应第一段的五种症状（同号一一对应）。
> **排序依据是"它需要什么"**：先看到 → 再懂 → 再会 → 再按路走 → 最后被验证。
> **每件事固定四段**：症状 → 它是什么 → 你要做什么 → 一句话。

### ① 让它看到该看的（上下文）

- **症状**：它忘了你说过的话；它拿到的是旧版本；关键那份它没看见
- **它是什么**：模型能用的，**只有此刻放在它眼前的东西**——你给它的，就是它知道的全部
- **你要做什么**：
  - 把该给的给到位（规矩、背景、这次要用的资料）
  - **告诉它哪份是最新的**——它分不清"现在这么做"和"以前这么做"
  - 别一次塞太多：**塞得越满，中间的东西越容易被漏掉**
- **一句话**：**你以为它知道，其实它没看见。**

### ② 让它懂你的业务（把老手脑子里的东西写出来）

- **症状**：它按通用套路干；不懂你们这行的规矩和黑话；**不懂也不问，自己猜**
- **它是什么**：模型的知识是**通用的**；你们这行真正管用的东西，大多在**老手的脑子里**，没写下来
- **你要做什么**：**把隐性知识显性化**——不是写手册，是写"这件事我们这儿怎么做 / 为什么这么做 /
  什么情况不能这么做"
- **判据**：**老手一句话能说清的那个坑，写下来它就不会再踩**
- **一句话**：**隐性知识不写出来，它就只能猜。**

### ③ 让它有该有的能力（工具与边界）

- **症状**：它干不了（够不着你的系统）；用了笨办法；**碰了不该碰的**
- **它是什么**：模型只会输出文字；**能做事的是你给它的工具**
- **你要做什么**：
  - 给它够得着的工具（查资料、读表、发消息）
  - **同时划圈**：它能读什么、能对谁发东西、能不能花钱
- **一句话**：**给能力的时候，顺手把圈划上。**

### ④ 让它按对的步骤走（工作流）

- **症状**：**它反复绕圈**（最高频）；跑偏；提前收工；说的和做的不是一回事
- **它是什么**：你给一个目标，它自己决定下一步——**步骤对不对，它自己不知道**
- **你要做什么**：
  - 把关键步骤写下来：先做什么、后做什么、**什么时候必须停下来问你**
  - 长任务要能接着上一段继续（不然每换一段就重来）
- **一句话**：**它不迷路，是因为你先把路画出来了。**

### ⑤ 让它能被验证（传统代码把关）★ 全场最重要的一页

- **症状**：它说做完了其实没做完；检查只做了表面；**自己评自己总说好**
- **它是什么**：**AI 的判断每次可能不一样**——所以它**不能当最后的对错判官**
- **你要做什么**：**AI 负责干，传统代码负责查**
  - 代码每次跑的结果都一样，所以能替你把「对不对」这一步**定死**
  - **会不会写不影响你用它**——写不用你写
  - 你要知道该要求什么：一段跑起来**会给出明确对错**的检查 / **每次都一样** / **卡在最容易出错的那一步**
- **附带一条**：**干活的和验收的不能是同一个**——自己评自己，一定说好
- **一句话**：**能让代码查的，别让 AI 自己说。**

> **底稿直接支持这一页**：验证类失败占 21.3%，且"有验证者也不够"——
> 现有验证大多只做表面检查。**加一层验证，ChatDev 成功率 +15.6%。**

## 第四段：搭多厚、归谁（判据 + 四档）

### 先定"搭多厚"：两句判据

> **错了赔得起吗？错了多久能发现？**

| | **马上能发现** | **很久才发现** |
|---|---|---|
| **赔得起** | 改一封内部通知的措辞 → **放手，随便试** | 整理内部知识库 → **加一个「每周扫一眼」** |
| **赔不起** | 给客户发报价单 → **发出去之前必须有人看一眼** | 动客户数据 / 对外自动回复 → **划圈 + 核对 + 留痕，一样不能少** |

**这一页回答的是"搭多厚"，不是"搭不搭"**：五件事在**任何一档**都得有，只是厚薄不同。

### 再定"归谁"：四档

**定位的两个问题**：**下一步谁定**（你 / 它）× **同时有几个在跑**（一个 / 多个）。

| 档 | 上屏名 | 这一圈归谁 | 它的风险 |
|---|---|---|---|
| **第 1 档** | 你问一句，它答一句 | **现成的**——你自己就是那一圈 | 几乎没有：你全程在场，代价最小 |
| **第 2 档** | 你定好步骤，它照着走 | **现成的**——但步骤和检查要你写进去 | **一步烂，后面全烂，而且错得很整齐，看起来很像对的** |
| **第 3 档** | 你给个目标，它自己跑 | **你自己搭**——你只在开头和结尾出现 | 跑偏没人知道 / 碰了不该碰的 / 该停不停 |
| **第 4 档** | 你定好分工，它们自己配合 | **你自己搭，还要定谁验收** | 互相甩锅 / 重复劳动 / 一条线坏了污染全局 |

**两条关键句**：

- 第 3 档：**它自己能验证的活，才敢让它长跑。**
- 第 4 档：**多一个执行者之前，先问「这一步是不是真的需要另一个脑子」。**

**落点**：**越往下走，五件事越不能省；但停在 第 1 档，完全没问题。**

## 第五段：收尾

### 什么时候别折腾（对这批听众最重要的一页）

- 一句话能说清的事，别写流程
- 一周做一次的事，别搭自动化
- **还没想清楚"什么样算做对"，别交给它自己跑**
- 先跑最简单的，不够再加。加之前先问：**谁维护它？它坏了谁发现？**

### 今天就能做的两件事

1. 挑一件你正在让 AI 干的事，对一遍五件事——**哪一件你根本没做？**
2. 如果是第 3 或第 4 档，先把这三条写下来：**它能碰什么**、**什么情况必须停下来问你**、
   **有没有一段代码能替它说"这步没问题"**

### 回到开场 + 正名

**你现在能答出"它为什么糊涂"了吗？答不出的那一条，就是你那一圈缺的东西。**
**这一圈有名字**——`Agent = Model + Harness`，搭它的这门手艺叫 **harness engineering**。
