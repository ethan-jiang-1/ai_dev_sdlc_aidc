## 当前定调（未经变更不得漂移）

1. **★ 核心命题（2026-09-21 用户定）**：**`Agent = Model + Harness`**。
   模型你只能选；**差别在模型外面那一圈**；搭对了它跑起来就不糊涂。**这门手艺叫 harness engineering。**
   原始出处：Trivedy《The Anatomy of an Agent Harness》，2026-03-10（见 `02_evidence/00-sources.md` §1）。
2. **★ 那一圈拆成五件事**（用户口述，按序不许换）：**看到什么 / 懂什么 / 会什么 / 怎么做 / 怎么验**。
3. **★ 五种症状有学术底稿**：MAST（NeurIPS 2025，14 种失败模式 / 3 大类）按五件事归位。
   最高频是**步骤重复 17.14%**，其次**推理与行动不一致 13.98%**、**用错误假设继续而不澄清 11.65%**。
   **频率数字不上屏**，只作排序底稿。
4. **症状与五件事一一对应、同序**（看到 → 懂 → 会 → 走 → 验）；五件事连续讲完，中间不插停顿页。
5. **全场最重要的一页 = P10「怎么验」**：**AI 负责干，传统代码负责查**；
   落点 **能让代码查的，别让 AI 自己说**。**会不会写不影响用**。
6. **四档降为"这一圈归谁"**（①② 现成 / ③④ 自己搭），只占 2 页；**不许讲成"越复杂越高级"**。
7. **harness 上屏两次**（P4 核心命题 / P15 正名），其余各页一律说「**模型外面那一圈**」。
8. **开场必须让听众先认领症状**（"你中过哪一条"），不认领后面没地方挂。
