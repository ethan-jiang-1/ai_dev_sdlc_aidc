## 当前定调（未经变更不得漂移）

1. **★ 核心命题**：**`Agent = Model + Harness`**。**模型决定上限；那一圈决定你能拿到多少**；
   那一圈搭对了，它跑起来就不糊涂。**这门手艺叫 harness engineering。**
   出处：Trivedy《The Anatomy of an Agent Harness》，2026-03-10（`02_evidence/00-sources.md` §1）。
   **v5 改口径**：原句"模型你只能选，选完大家都一样"**太满**——"换模型 ≠ 性能不变"一撞就破；
   已按行业侧证据改为"决定上限 / 决定拿到多少"。
2. **★ 那一圈拆成五件事**（按序不许换、不许合并）：**看到什么 / 懂什么 / 会什么 / 怎么做 / 怎么验**。
3. **★ 五种症状有学术底稿**：MAST（NeurIPS 2025，14 种失败模式 / 3 大类）——
   **13 个归位到五件事，1 个未采用**（隐瞒关键信息，多 agent 专属）；**③ 无 MAST 对应**。
   最高频**步骤重复 17.14%**，其次**推理与行动不一致 13.98%**、**用错误假设继续而不澄清 11.65%**。
   **频率数字不上屏**。
4. **症状与五件事一一对应、同号同序**（看到 → 懂 → 会 → 走 → 验）；五件事连续讲完（P7–P13），
   中间不插停顿页。**⑤ 因要回答"那段检查谁写"拆 P12 / P13 两页**（拆页不是合并）。
5. **★ P4 必须回答「等下一代模型不就行了」**——**这一圈不会消失，只会移动**：
