## 当前定调（未经变更不得漂移）

1. **★ 核心命题**：**`Agent = Model + Harness`**。模型你只能选；**差别在模型外面那一圈**；
   搭对了它跑起来就不糊涂。**这门手艺叫 harness engineering。**
   出处：Trivedy《The Anatomy of an Agent Harness》，2026-03-10（`02_evidence/00-sources.md` §1）。
2. **★ 那一圈拆成五件事**（按序不许换）：**看到什么 / 懂什么 / 会什么 / 怎么做 / 怎么验**。
3. **★ 五种症状有学术底稿**：MAST（NeurIPS 2025，14 种失败模式 / 3 大类）按五件事归位。
   最高频**步骤重复 17.14%**，其次**推理与行动不一致 13.98%**、**用错误假设继续而不澄清 11.65%**。
   **频率数字不上屏**。
4. **症状与五件事一一对应、同号同序**（看到 → 懂 → 会 → 走 → 验）；五件事连续讲完，中间不插停顿页。
5. **★ P3 必须回答「等下一代模型不就行了」**（v3 补）——**这一圈不会消失，只会移动**：
   每个组件都编码了一个"模型做不到"的假设。**不回答它，整场必要性立不住。**
6. **搭多厚由两句判据决定**（错了赔得起吗 / 多久能发现，P11）——回答"搭多厚"，不是"搭不搭"。
7. **全场最重要的一页 = P10**：**AI 负责干，传统代码负责查**；落点 **能让代码查的，别让 AI 自己说**。
   **会不会写不影响用。**
8. **四档降为"这一圈归谁"**（第 1–2 档现成 / 第 3–4 档自己搭），只占 1 页；**不许讲成"越复杂越高级"**。
9. **harness 上屏两次**（P4 核心命题 / P15 正名），其余各页一律说「**模型外面那一圈**」。
10. **编号三套不许撞车**：症状 / 五件事 = `①②③④⑤`；**四档 = 第 N 档**；判据 = 那两句。
11. **上屏只留作者 / 机构 + 年份**，不留公司名、产品名、工具名。
12. **本场原则上不引数字**：唯一例外是 P4 的 Top 30 → Top 5（须标 ⚠️ 厂商自述）。
13. **不套用其他 talk 的红线**——本场红线在 `CONTEXT.md` 第四 / 六节，是本场自己的。
