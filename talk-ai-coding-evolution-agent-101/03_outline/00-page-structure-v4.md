## 七、计时与压缩

| 段 | 页 | min |
|---|---|---:|
| 开场 | P1–P3 | 3.5 |
| 核心命题 | P4–P5 | 4.5 |
| 五件事 | P6–P13 | 11.5 |
| 搭多厚、归谁 | P14–P16 | 4.0 |
| 收尾 | P17–P19 | 4.0 |
| **正文合计** | **19 页** | **27.5** |
| 停顿页 B1–B2 | 2 张 | ≈ 0.7 |
| **总计** | **21 张** | **≈ 28.2 min（约 28 min）** |

- **留约 1.5 min 现场缓冲**；P3 的认领互动最容易超时，主持时从这里抢时间。
- **短场次（≈24 min）的删法**：删 **P2**（场景改口播并入 P3）、**P7**（总览并入 P6）、
  **P16**（并入 P15）、**P18**（并入 P19）→ **15 页正文 ≈ 24.0 min + 保留 1 张停顿页（B1）≈ 24.4 min**。
  再压就必须动 **P13**（"那段检查谁写"降为 P12 页脚一句 → 14 页正文 ≈ 23.5 min），
  **代价是撤销 v4 修复 #11 的可执行性**。
  **五件事 P8–P12 五页不许合并、不许换序**——**压到 20 min 就得动五件事本身，超出本场纪律**。

## 八、逐页讲法 [不上屏]（讲法只在本节，04 里没有）

> 讲者用；**不进渲染**。带「口播」的是可以照着说的话。

| 页 | 讲法 |
|---|---|
| **P1** | 不解释封面。开场只说一句：**"今天只回答一个问题——同一个模型，为什么在别人手里好用，在你手里糊涂？"** |
| **P2** | **约 30 秒口播，不要念屏。** 讲完停一秒，再说："这时候你会怪模型——先别怪。" 这一页不出任何术语 |
| **P3** | 念完**停 3–5 秒**，问「**你中过哪一条？不用说出来**」（房间可能有上级在场：不点名、不举手）。**不做这一步，后面五件事没地方挂**；**全场最容易超时的一页** |
| **P4** | 先认账"模型确实一直在变强"，再给落点。**这是全场唯一的趋势判断，也是听众最可能的抵抗点**——不回答，整场必要性立不住 |
| **P5** | `harness` **全场只在这里和结尾出现两次**，其余各页说"模型外面那一圈"。**口播两句就够**：① 比喻「**脑子继续换，身体不用每次重新造**」——**这是中文界的提炼，不是官方原话**；② 旁证「**上个月有家厂商干脆把这一圈做成了产品开源出来，卖点就是一行代码 + 随便换模型**」。**不点产品名、不报任何数字**。口播可补原意：模型给智能，那一圈让智能真的能干活 |
| **P6** | **全片主线页**——先把"信噪比"说成人话（**有用的多、没用的少**），再给"**按图索骥**"（给它一张索引让它自己去找）。**只点名一次，后面五页沿用**。别当技术词讲：听众知道音响里的信噪比就够了。**多说一句"少即是多"，这页就立住了** |
| **P7** | **只出名字与顺序，半分钟过**，细节留给下面五页；说明与 P3 的五种症状**同号对应**；**收到上一页**："那个比例，就靠这五件事调上去" |
| **P8** | 对应症状 ①。**别讲"上下文窗口"这类词**；"上下文"这个词只在本页命名一次，之后才可沿用 |
| **P9** | **上屏一律说"把老手脑子里的东西写出来"**；"隐性知识显性化"是本目录内部名，**不上屏、不进讲稿**。这里要补一个听众一听就"对对对就是这样"的老手坑（缺口见 `../CURRENT.md`） |
| **P10** | 对应症状 ③（含"碰了不该碰的"）。**不说"权限 / 沙箱"** |
| **P11** | **"来回兜圈子"是最高频的失败**——只口播，**不上屏任何百分比** |
| **P12** | **全场最重要的一页**。必须说清两件事：① **它不是拿来干活的，是拿来做质量把关的**；② **写不用你写**。数字（验证类失败占比等）**不上屏**。下一页回答"那谁写" |
| **P13** | **这页只有 30 秒，但不讲不行**——不讲，"让程序查"对不写代码的听众就是一句空话。依据是 Anthropic 2026 的"生成与评判分开"，但**不上屏、不署名**（署名只留给 P4 / P5）。口播可换成白话：**"干活的和判它干得好不好的，得是两拨人"** |
| **B1** | 念完**静默 5–8 秒** |
| **P14** | **这页回答的是"搭多厚"，不是"搭不搭"**；不要讲成"风险评估" |
| **P15** | **不许讲成"越复杂越高级"**；第 3–4 档是听众最容易上头的地方。"工作流 / 智能体"只在本页命名一次 |
| **P16** | 这页只做一件事——**别让听众把 P14 的"四个格子"和 P15 的"四个档位"混成一个** |
| **B2** | 念完**静默 5–8 秒** |
| **P17** | **这页比四档更容易被跳过，不能省**——省了本场就变成劝人上自动化 |
| **P18** | 第 2 条要**明确接回 P13**，否则听众回去还是不知道检查从哪来。**口播可点一句**：该试的不是"哪个模型更强"，是**你这件事交给这套组合要花多少、成不成** |
| **P19** | `harness` 全场第二次、也是最后一次上屏。一句话收，**不再展开定义** |

## 九、交付前自检

1. **每页只答一步**，L1 能写成一句疑问句或半句推导。
2. **每页至少一个 takeaway**；拿不到 = 删或合并。
3. **大字只有一句**；P5 / P12 之外不用最大字号。
4. **上屏无行话**（`../CONTEXT.md` 第四 / 五节），`harness` 只在 P5 / P19，**页脚等级用日常说法**。
5. **数字零上屏**（含 Top 30→Top 5 与行业侧数字）。
6. **署名只有 P4 / P5**。
7. **五件事一一对应、同号同序**；每页讲得出它对应的那条症状。
8. **术语按三段式入场**，一页最多命名一个新词。
9. **停顿页同时收上启下**，不复述上一页。
10. **上屏文案只能来自 `../04_drafts/ppt-text-v4.md`**；本文件的「讲法」一律不进渲染。
