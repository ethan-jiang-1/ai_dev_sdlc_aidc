# 驾驭 AI 手册 · 页版 v5 · 20 页（一页一个提醒）

> **[INTERFACE]** 本文件是**手册的页版**（长版讲义在 `实战手册-v5.md`），**供 PPT Agent 直接消费**。
>
> **与 `ppt-text-v5.md` 的关系**：两个文件**共用同一套记号约定**（下面这四条），但**字段表各自独立**
> （演讲有 `结论句/命名/版式`，手册页版没有；手册页版有 `提醒/要点`，演讲没有）——下游按各自的字段表解析。
>
> **怎么切页（下游请按这个来）**：
> 1. **页块 = 以 `### ` 开头的那一块**（`### P1`…`### P20`）——**共 20 个页块**；
> 2. **`## ` 开头的是分段**，**不是页**；**第一个页块之前的头部不是页**；
> 3. **页块之间必有 `---`**。
>
> **优先级记号（只有这四个，写在方括号里）**：
>
> | 记号 | 含义 |
> |---|---|
> | `[必上]` | **本页那一句提醒**——**每页恰好一条，就是"一页一个提醒"** |
> | `[必给]` | 必给材料（**可多条、可含表**）——装不下时优先保它，再保 `[必上]` 那句 |
> | `[可选]` | 装得下就上，装不下就丢 |
> | `[例]` | 具体例子——**优先上** |
>
> **字段写法规则**：**方括号里只放优先级记号**，其他说明一律用**圆括号**；
> 同一字段允许在同一页重复出现，按出现顺序渲染。
>
> **字段表**：

| 字段 | 含义 |
|---|---|
| `L1 标题` | 画面上的大字标题 |
| `L2 主视觉` | 画面主体（图形/示意） |
| `要点 [必给]` | 本页必给的材料，**可多条、可含表** |
| `要点 [可选]` | 可丢的材料 |
| `例子 [例]` | 具体案例，供挑选 |
| `提醒 [必上]` | **本页那一句提醒（每页恰好一条）** |
| `L4 页脚` | 页码 |

> 红线：不出现具体产品名、不引外部数字、不用研发圈行话。

### P2 · 它其实只看五样东西

- **L1 标题**：**它进门第一天，先看这五样**
- **L2 主视觉**：五个抽屉并排，分别标 ①–⑤
- **要点 [必给]**：
  - **① 工作空间**：我在哪儿？有哪些东西？哪个是让我动的？
  - **② 知识**：你们这行的规矩、这件事的来龙去脉，在哪？
  - **③ 能力**：我能用什么？能碰什么、不能碰什么？
  - **④ 流程**：先做什么、后做什么、什么时候停？
  - **⑤ 规矩与约束**：什么必须、什么绝对不行、谁验收、查不查得到？
- **要点 [可选]**：
  - **它糊涂，几乎总是因为五样里的某一样，你没摆**
  - **这五样，就是前面那场分享里说的那五件事**：工作空间＝看到什么 ｜ 知识＝懂什么 ｜ 能力＝会什么 ｜ 流程＝怎么做 ｜ 规矩与约束＝怎么验
- **提醒 [必上]**：**你的活不是"把事想清楚"，是把这五样摆到它看得见的地方。**
- **L4 页脚**：页码 2

### P3 · 它一次理顺不了

- **L1 标题**：**别指望第一轮就对——它只能靠反复打磨**
- **L2 主视觉**：一条从粗糙到顺滑的曲线
- **要点 [必给]**：
  - 模型很难一下子把一件事完全理顺
  - **人也一样**——你理顺一件事，不也是一步一步梳理出来的吗？
  - 你带新同事，也是先交代个大概，它做错了你再说一句
- **提醒 [必上]**：**这本手册不是一张"一次过"的清单，是一个循环。**
- **L4 页脚**：页码 3

### P4 · 主线：一个循环

- **L1 标题**：**摆 → 跑 → 看 → 补一条 → 再跑**
- **L2 主视觉**：五个箭头首尾相接的环
- **要点 [必给]**：
  - **摆**：五个地方各放一个初版
  - **跑**：交给它做一次
  - **看**：它糊涂在哪儿
  - **补一条**：补进对应那个地方（**一次只补一条**）
  - **再跑**：回到第二步
- **提醒 [必上]**：**打磨三轮，这件事基本就稳了。**
- **L4 页脚**：页码 4

### P5 · 开摆之前（一）：挑一件真事

- **L1 标题**：**先挑一件真事，别拿假的练手**
- **L2 主视觉**：三格漏斗
- **要点 [必给]**（三个条件，都满足才值得搭）：
  - **你正在做**的（不是打算做的）
  - **会重复做**的（一次性的不值得搭）
  - **做错了有代价**的（错了没人管，也不用搭）
- **要点 [可选]**：
  - **可以拿来练的**：给客户的报价单、每周汇总、对外通知、整理资料、回复常见问题
  - **别拿来练的**：一辈子做一次的事、**你自己都还没想清怎么做的事**、纯属好玩的事
- **例子 [例]**：
  - 写下来：这件事是 ____；一周 __ 次；**做错了会 ____**
  - **写不出"做错了会怎样"，就先别往下走**
- **提醒 [必上]**：**这件事值不值得搭，取决于"错了会有多疼"。**
- **L4 页脚**：页码 5

### P6 · 开摆之前（二）：你盯多紧

- **L1 标题**：**先定你盯多紧——问自己两句话**
- **L2 主视觉**：一个四格
- **要点 [必给]**：
  - **错了赔得起吗？**
  - **错了多久能发现？**

  |  | **马上能发现** | **很久才发现** |
  |---|---|---|
  | **赔得起** | 放手，随便试 | 加一个"每周扫一眼" |
  | **赔不起** | 发出去之前必须有人看一眼 | **划圈 + 核对 + 留痕，一样不能少** |

- **要点 [可选]**：
  - 这一步回答的是**"搭多厚"，不是"搭不搭"**
  - 五个地方**在任何一档都得摆**，只是厚薄不同
- **提醒 [必上]**：**错了我睡不睡得着——这就是你该用多大劲。**
- **L4 页脚**：页码 6

### P7 · 开摆之前（三）：它在第几档

- **L1 标题**：**再定你放多少手**
- **L2 主视觉**：一根从"你全程盯着"到"你只在两头"的滑杆
- **要点 [必给]**（四档）：
  - **第 1 档** 你问一句，它答一句 → **你全程盯着**
  - **第 2 档** 你定好步骤，它照着走 → **你定一次，它每次照做**
  - **第 3 档** 你给个目标，它自己跑 → **你只在开头和结尾出现**
  - **第 4 档** 你定好分工，它们自己配合 → **你定分工，还得定谁验收**
- **要点 [可选]**：
  - 两个问题定档：**下一步谁定？**（你 / 它）× **同时有几个在跑？**（一 / 多）
  - **第 1–2 档里那些检查是现成的**——别自己重搭，把它用起来就行
- **提醒 [必上]**：**停在第 1 档，完全没问题。** 越往下走，五个地方越不能省。
- **L4 页脚**：页码 7

### P8 · ① 工作空间：目录结构对不对？

- **L1 标题**：**它一进门，第一件事就是看**
- **L2 主视觉**：一个分好层的文件夹树（资料 / 半成品 / 产出 / 别碰的）
- **要点 [必给]**：
  - **目录结构**：资料、半成品、产出、**别碰的**，分开摆
  - **名字**：一眼能看懂（`客户资料-最新` 比 `新建文件夹` 强得多）
  - **给它一块地盘**：它的工作区单独一块，**跟你的东西不混**
- **要点 [可选]**：
  - **哪份为准**：作废的挪走，或者写一句"以 ____ 为准"
  - **目录结构看起来还行，它才敢动手**
- **例子 [例]**：
  - **没摆清楚，就是这样**：全堆在一个文件夹里；名字叫"最终版-改"；该动的和不该动的混在一起——**它只能猜**
- **提醒 [必上]**：**它一眼能看出"东西在哪、该动哪个、哪个别碰"。**
- **L4 页脚**：页码 8

### P9 · ① 加一条：先问合规

- **L1 标题**：**摆之前先问一句：哪些东西根本不能进这个工作空间**
- **L2 主视觉**：一个带红线的框，框外标着"客户明细 / 人事 / 未公开"
- **要点 [必给]**：
  - 有些东西不是"要不要给它看"的问题，是**能不能往外发**的问题
  - **先问你们管技术的或管合规的同事一句**，再动目录
- **要点 [可选]**：
  - 典型的三类：**客户明细、人事资料、还没公开的东西**
  - 这一句不问，后面摆得再漂亮也可能**整件作废**
- **提醒 [必上]**：**合规不是"以后再说"的事——它是摆之前的第一问。**
- **L4 页脚**：页码 9

### P10 · ② 知识：放哪儿

- **L1 标题**：**它不知道，也不会来问**
- **L2 主视觉**：老手脑子里 → 写下来
- **要点 [必给]**：
  - 它懂的是**通用套路**；你们这行真正管用的，在**老手脑子里，没写下来**
  - 它**不知道自己不知道**——所以**别指望它来问**
  - 要写的是三样：**怎么做 ／ 为什么 ／ 什么情况不能这么做**
- **要点 [可选]**：
  - 放在**它找得到的地方**
  - **一次写下来，以后都不用再说**
- **例子 [例]**：
  - "折扣不能低于审批过的下限"
  - "这类客户不能直接给结论，要先给过程"
  - "这几件事必须先问过我"
- **提醒 [必上]**：**新人照这三条能不出错，才算摆清楚。**
- **L4 页脚**：页码 10

### P11 · ③ 能力：放哪儿

- **L1 标题**：**它只会写字——真能动手的，是你给的**
- **L2 主视觉**：一只手递工具，同时画一个圈
- **要点 [必给]**：
  - 给它够得着的工具（查资料、读表、发消息）
  - **同时把圈划上**：**能读什么 ／ 能对谁发东西 ／ 能不能花钱**
- **要点 [可选]**：
  - **给能力的时候最危险**——你没说的，它就会试
  - **它能做的不缺，不能做的不给**
- **例子 [例]**：
  - 能读：这几张表、这个文件夹
  - **不能读**：客户明细、人事资料
  - **发之前要不要我看**：先定下来
- **提醒 [必上]**：**三句话能说清它的边界，才算摆清楚。**
- **L4 页脚**：页码 11

### P12 · ④ 流程：放哪儿

- **L1 标题**：**它自己决定下一步——可走得对不对，它自己不知道**
- **L2 主视觉**：一条路 + 两个路标
- **要点 [必给]**：
  - 把关键的几步写下来：**先做什么 → 再做什么 → 最后做什么**
  - 最要紧的是：**什么情况必须停下来问你**
- **要点 [可选]**：
  - **步骤写太细**，它反而在细节里打转
  - **没写停手条件**，它干一半就宣布完成，你还以为它做完了
  - 长活要能**接着上一段往下干**
- **例子 [例]**：
  - "先核对数据，**再**套模板"
  - "金额对不上**就停下来问我**，不要自己改"
  - "对外的东西**一律先给我看**"
- **提醒 [必上]**：**它不用猜就知道该在哪儿停，才算摆清楚。**
- **L4 页脚**：页码 12

### P13 · ⑤ 规矩与约束：放哪儿

- **L1 标题**：**它说"做好了"——但它评自己，当然说好**
- **L2 主视觉**：四根柱子：必须做的 ／ 绝对不能做的 ／ 谁验收 ／ 查不查得到
- **要点 [必给]**（摆四样）：
  - **必须做的**（规矩）
  - **绝对不能做的**（约束）
  - **谁验收**——**干活的和验收的，不能是同一个人**
  - **出了事查不查得到**——它每一步做了什么、用了哪份数据
- **要点 [可选]**：
  - **只在最后看一眼**，往往已经来不及
  - **每一步都查**——没必要，噪声还大
  - 选检查的窍门：**你平时手工要复查哪一项，就把哪一项交给**代码****
- **例子 [例]**：
  - 金额对不对得上 ／ 该填的有没有空着 ／ 日期编号格式合不合 ／ 前后数字能不能对上
- **提醒 [必上]**：**它说做好了的时候，你能拿出一条会报错的检查。**
- **L4 页脚**：页码 13

### P14 · ⑤ 加一条：查不到的错怎么办

- **L1 标题**：**有一类错，检查也查不到**
- **L2 主视觉**：一条分岔路：能查的 → 机器；查不到的 → 人眼
- **要点 [必给]**：
  - 有些错（比如"这句话该不该这么说"、"这个判断对不对"）**没法用"每次都一样"的东西验**
  - 这类错**只能靠"错了多久能发现"兜底**
- **要点 [可选]**：
  - 把它安排成**很快就能看到结果**的样子：先发小范围、先给一个人看、先跑一次不发出去
- **提醒 [必上]**：**查不到的错，就把它挪到"马上能发现"那一类去。**
- **L4 页脚**：页码 14

### P15 · 跑：别追求一次到位

- **L1 标题**：**第一次别全上**
- **L2 主视觉**：五个地方里先点亮两个（① 和 ③）
- **要点 [必给]**：
  - 先把 **①（工作空间）** 和 **③（能力与圈）** 摆好，让它跑一次
  - **允许它错**——**它错的地方，正是你没摆清楚的地方**
- **要点 [可选]**：
  - 第一次跑完，你多半会发现：**有两三个地方，你以为说清了，其实没说清**
- **提醒 [必上]**：**第一轮不是为了一次做对，是为了把"你没说清的地方"露出来。**
- **L4 页脚**：页码 15

### P16 · 看：它糊涂在哪儿

- **L1 标题**：**它糊涂的那一条，就是你没摆清楚的那个地方**
- **L2 主视觉**：五行对照表
- **要点 [必给]**：

  | 它的表现 | 你哪个地方没摆清楚 |
  |---|---|
  | 找不到东西；动错地方；把作废的当成最新的 | **① 工作空间** |
  | 按通用套路干，不懂你们的规矩，还不问 | **② 知识** |
  | 干不了；用笨办法；碰了不该碰的 | **③ 能力** |
  | 来回兜圈子；跑偏；提前收工 | **④ 流程** |
  | 说做完了其实没做完；自己评自己总说好 | **⑤ 规矩与约束** |

- **提醒 [必上]**：**别问"它为什么这么笨"，问"我哪个地方没摆清楚"。**
- **L4 页脚**：页码 16

### P17 · 补：一次只补一条

- **L1 标题**：**补进哪个地方，看它在哪儿糊涂**
- **L2 主视觉**：五个抽屉，有一个被标红
- **要点 [必给]**：

  | 它在哪儿糊涂 | 你补什么 | 补进 |
  |---|---|---|
  | 把作废的当最新的 | "以 ____ 为准"，或把作废的挪走 | **①** |
  | 找不到该用的东西 | 调目录、改名字，或**给它一张索引** | **①** |
  | 不懂你们的规矩 | 补一条"不能这么做的情况" | **②** |
  | 够不着 / 越界 | 补工具，或补一句边界 | **③** |
  | 干一半就停 / 绕圈子 | 补一个停手条件 | **④** |
  | 说做好了其实没做完 | 补一条**每次都一样**的检查 | **⑤** |
  | 说不清谁负责 | 定下**谁验收** | **⑤** |

- **提醒 [必上]**：**一次只补一条**——补多了你自己也记不住，它更乱。
- **L4 页脚**：页码 17

### P18 · 打磨三轮，长什么样

- **L1 标题**：**同一个报价单，补了三轮**
- **L2 主视觉**：四格时间线（刚摆好 → 补① → 补② → 补⑤）
- **要点 [必给]**：
  - **第 1 轮**：它用了上周的模板 → 补①"**以本周版为准，上周版别动**"
  - **第 2 轮**：报价单没写有效期 → 补②"**必须带有效期，默认 30 天**"
  - **第 3 轮**：折扣和审批下限对不上，它还说做好了 → 补⑤"**两处金额必须相等，不一样就报错**"
- **要点 [可选]**：
  - **加之前也要减**：上一轮加的东西还在起作用吗？
  - 模型变强之后，有些规矩就该退休——**那一圈会移动**；只加不减，越堆越厚
- **提醒 [必上]**：**补三轮，你只用看检查结果。**
- **L4 页脚**：页码 18

### P19 · 什么时候算"驾驭住了"

- **L1 标题**：**你敢只看检查结果，就把它交出去**
- **L2 主视觉**：一个人把稿子推出去，只看一眼检查结果
- **要点 [必给]**：
  - 到这一步，你不再需要逐字看它写的东西
  - **你有东西能替它说"这步没问题"**
- **要点 [可选]**：
  - 没到这一步，说明 ⑤ 还没摆清楚
- **提醒 [必上]**：**从"我盯着它"到"我看着检查"——这就是驾驭住了。**
- **L4 页脚**：页码 19

### P20 · 什么时候别用它

- **L1 标题**：**有些事，别折腾**
- **L2 主视觉**：一块"刹车"标牌
- **要点 [必给]**：
  - 一句话能说清的事，**别为它搭这一套**
  - 一周做一次的事，**别搭**
  - **还没想清楚"什么样算做对"，别让它自己跑**
  - **你自己都不确定的事，别指望它替你确定**
- **要点 [可选]**：
  - 最后自问一句：**这一条是让它更准，还是只是我觉得更保险？**
- **提醒 [必上]**：**它糊涂的时候，先别怪它——回头看看，是这五个地方的哪一个没摆清楚。**
- **L4 页脚**：页码 20
