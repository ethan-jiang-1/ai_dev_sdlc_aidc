## Deer Valley → Engelberg：五个月的变化

这是两场 retreat 之间最核心的叙事：

| | Deer Valley (2026-02) | Engelberg (2026-07) |
|---|---|---|
| **语气** | 犹豫、信念、"可能有点东西" | 自信、证据、"价值就在这里" |
| **讨论焦点** | 工具：什么是可能的、对人有什么影响 | 规模化：团队 → 企业级模式 |
| **实验阶段** | 早期实验 | 数十个 agentic engineering 模式库已被编目 |
| **关键词** | 未知、探索 | **Harness Engineering**（这个术语在 Deer Valley 时还不存在） |
| **参与者在做什么** | 讨论 agentic 开发**可能**长什么样 | **所有人都在生产环境中交付** agentic 系统 |

> Giles Edwards-Alexander：*"Where Deer Valley had hesitancy and a belief that there was something here even if we weren't yet sure what it was, Engelberg had confidence: the value is here. This was not a conference for true believers: the evidence is in."*

> Greg Herlein（参会者）：*"Everybody in the room was doing it. Shipping it. Not slides — production."*
