# Talk 页面结构（27 页全素材索引，已被 23 页现场版取代）

> ⚠️ 现场版见 [`00-page-structure-23.md`](./00-page-structure-23.md)（P1–P23，45 min）。本文件保留为 27 页全素材索引（每页标预算分钟，合计约 48 min）。**无 demo。**

## 开场（4 min）

1. **封面** —— 一人公司，AI Coding 要掌握到多深？（0.5）
2. **钩子** —— 两年里你的角色一直在变：写 prompt → 挑 context → 搭环境 → 写循环 → 排图；你不是在追新工具，是被模型往上推（1.5）
3. **路线图** —— 五层 → 为什么根本是 harness → 固定 vs 灵活 → DSH（1）

## 第一幕 · 五层演变（15 min）

4. **发动机** —— 模型越强，人机互动行为越变，动作粒度变粗（2）
5. **Prompt** —— 说话者：我该说什么（1.5）
6. **Context** —— 策展者：它该看到什么（2）
7. **Harness** —— 环境工程师：它在什么系统里跑（2.5，埋雷：这是承重墙）
8. **Loop** —— 控制流作者：何时再跑一次（1.5）
9. **Graph** —— 编排者：多 agent 怎么组织（1.5）
10. **叠加观 + 成熟度** —— 不是换代是叠加；前三层成熟、后两层叙事期（2）

## 第二幕 · 根本还是 harness（10 min）

11. **转折** —— 五层讲完，根本还是 harness：可靠性承载体（1）
12. **定义** —— Agent = Model + Harness（1）
13. **两套控制** —— Guides（前馈）+ Sensors（反馈）（2）
14. **computational vs inferential** —— 确定 vs 概率（1.5）
15. **抓要害** —— 模型给能力，harness 给可靠性；圈住 / 拦住 / 看清（2.5）
16. **承重墙** —— loop / graph 都站在 harness 上（1）
17. **反面证据** —— 2026 CVE：authorize at execution, not at generation（1.5）

## 第三幕 · 固定 vs 灵活（9 min）

18. **抉择** —— harness 这一格，用固定的还是灵活的？（1）
19. **固定的好** —— Codex / Claude Code 开箱即用（2）
20. **固定的卡** —— 想改 harness 本身：挂 MCP / skill / knowledge map 受限（3）
21. **本质（不绝对）** —— 不是别用现成，是别只能现成；灵活 harness = 装自己的 + 借现成的（2）

## 第四幕 · DSH（5 min）

22. **DSH** —— 一个灵活的 harness，能改 harness 本身（1）
23. **双向灵活** —— 装自己的（挂模型 / 挂工具 / 换后端 / skill / knowledge map / 门禁）+ 借现成的（vendor adapter / 组件复用）（2.5）
24. **哲学** —— Agents follow enforced gates far more reliably than prose conventions（1.5）

## 收尾（3 min）

25. **回答** —— 一人公司要掌握到 harness 层；不用从零造，但要能改（1.5）
26. **带走一句** —— 装自己的，借现成的（候选，待定）（1）
27. **Q&A**（0.5）
