# CLAWTIME 贵客松模板留白版

本目录的最终模板由三种页面组成：

- `slide-start.png`：开始页。使用原始完整城市视觉。
- `slide-content.png`：内容页。只保留进一步缩小的顶部 LOGO；中间与底部均留白，供正文、图表或图文自由排版。
- `slide-end.png`：结束页。使用原始完整城市视觉。

对应的 PowerPoint 模板为 `CLAWTIME贵客松模板-留白版.pptx`，三页顺序与上述页面一致。内容页用于日常正文、图表和图文排版；开始页、结束页用于开场与收尾。

## 使用方式

1. 新建一份演示稿时，以 `CLAWTIME贵客松模板-留白版.pptx` 为起点。
2. 第 1 页作为开始页，替换“示例标题”为演示主题、项目名或活动名称。
3. 第 2 页作为内容页。按需要复制该页来增加章节、正文、图表、图片或表格；页眉 LOGO 保持不动，其余区域均可自由排版。
4. 第 3 页作为结束页，替换“示例标题”为致谢、联系方式或结束语。
5. `slide-start.png`、`slide-content.png`、`slide-end.png` 是三种页面的视觉预览，用于快速确认页面类型；正式编辑应在 PPTX 中完成，而不是在 PNG 上修改。

内容页的设计约定是“只保留缩小后的页眉 LOGO”。新增内容不要覆盖页眉；页面下方不保留固定装饰图，以便充分使用整张画布。
