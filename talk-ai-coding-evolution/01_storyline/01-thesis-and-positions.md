# 核心论点与立场（v1.2 摘要）

> 详细论证与证据分布见 [`00-storyline-map.md`](./00-storyline-map.md)（各幕要点）与 `../02_evidence/00-absorption-plan.md`（故事线资产 §一）。

1. **叠加上升观**：五层不是换代，是叠加——每一层都还踩着下面。论据：扳手/螺丝刀比喻（06 章）。
2. **成熟度标尺**：前三层（Prompt / Context / Harness）成熟可信；后两层（Loop / Graph）叙事期、低置信度——"火六周就被接棒"本身就是证据。
3. **harness 是承重墙**：这是**我们的判断**，不是报告背书（报告把 Context 与 Harness 并列）。用三线撑：结构线（loop/graph 实例化 harness）、哲学线（验证梯渗透 + GraphARC 门禁）、风险线（2026 CVE）。
4. **可靠性是系统的属性**：模型给能力，harness 给可靠性；确定性优先（computational > inferential）。
5. **固定 vs 灵活（不绝对）**：不是"别用现成"，是"别只能现成"；灵活 = 装自己的 + 借现成的。

## 一句话主线（源自 00-storyline-map）

模型越强，人机互动行为越变——人从"亲手做"被推成"设计模型怎么做"；一人公司要掌握到 **harness 这一层**：不用从零造，但要能改。
