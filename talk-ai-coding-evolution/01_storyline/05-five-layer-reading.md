# 五层叠加故事线 · 解读

> 源：`rawdata_ai-coding-evolution-final/final_v4.md`。本页是对"五层叠加"作为**故事线**的解读，
> 不是素材摘录，而是提取它"为什么能讲成一个好故事"的结构。故事线定稿时，从这里改起。

## 为什么它是"故事"，而不是时间线

### 1. 它有一个发动机，而不是五个新词

五层背后只有**一个**驱动机制：

> 模型越强，单次交互的边际工程收益越低，工程杠杆点就往上移。

五个 era 只是这同一台发动机的五次点火。好故事的第一个特征：**一个因，五个果**。
听众只需记住这一句话，五层都能自己推导。四次"换挡"都写成同一种句式（源报告）：

```
Prompt → Context：模型够强 → 不用把事实塞进 prompt
Context → Harness：环境受控 → 不用在 context 里写规则
Harness → Loop：运行受控 → 不用人决定"再来一次"
Loop → Graph：单 agent 够强 → 不用手动拆任务给谁
```

每一步都是"能力到位后，某个手工动作被上移/自动化"——这是"杠杆点上移"最具体的说法。

### 1.5 这台发动机有两面：模型在涨，**人机互动行为也在变**

"杠杆点上移"是从模型侧看的；从**人**这一侧看，是**人机互动的行为一直在变**——模型每强一步，
就把人往上推一格：人从"亲手做"，逐步变成"设计别人（模型）怎么做"。

| 层 | 模型能力涨到 | 人的互动行为 | 人的新身份 |
|---|---|---|---|
| Prompt | 能听懂指令 | 我写对那句话 | 说话者 |
| Context | 能记得更多、但会 context rot | 我挑它看什么 | 策展者 |
| Harness | 能调工具、但乱跑有风险 | 我搭它运行的环境 | 环境工程师 |
| Loop | 一次能做完、但不主动重复 | 我写让它反复跑的循环 | 控制流作者 |
| Graph | 单 agent 能干、但协调不过来 | 我组织多个 agent | 编排者 |

五层引用链里最动人的几句，其实都在说"人退出了哪一步"：

- Boris Cherny（Claude Code 负责人）：*"I don't prompt Claude anymore. I have loops running that prompt Claude. My job is to write loops."*
- Peter Steinberger：*"You shouldn't be prompting agents anymore. You should be designing loops that prompt your agents."*

→ 人没有消失，人的**动作粒度变粗了**：写一句话 → 写一个循环 → 排一个图。
这正是听众自己的成长史，是"引发共鸣"最直接的那根线。

### 2. 它是一个"问题上爬了五层楼"的递进

五层其实是**同一个问题在爬楼梯**——每一层的答案一旦不够用，问题就往上挪一格：

| 层 | 问的问题 | 答案的局限 |
|---|---|---|
| Prompt | 我该**说**什么？ | 说对了，但模型看不到事实 |
| Context | 它该**看到**什么？ | 看到了，但它在错误的环境里乱跑 |
| Harness | 它在什么**系统**里跑？ | 跑一次对了，但一次不够 |
| Loop | 何时再跑一次？ | 一个人跑通了，但一个人不够 |
| Graph | 多 agent 怎么**组织**？ | —— |

这个递进就是主线，天然是"往上走"的形状，每一层都站在前一层够不到的地方。

### 3. 它的立场（反常识点）是"叠加而非替代"

没有立场的故事只是时间线。这份报告的立场很硬：**新范式没有取代旧范式，五层同时活着。**
它直接打脸听众的默认假设（"prompt 过时了，现在是 XX"）。这个反转本身是记忆点，也给了
一句可带走的话："不是换代，是叠加。"

### 4. 它自带"诚实的标尺"，反而更可信

最难得的一点：故事一边往上涨，一边自己踩刹车——**成熟度向上递减**。
前三层有量化机制（context rot）、独立证据（METR / SWE-bench）、真实事故（2026 CVE）；
后两层定义才一两个月、无基准。它甚至把"Loop 火了六周就被 Graph 接棒"这个尴尬事实，
直接当作"这层还没沉淀"的证据。**一个敢自己戳破自己泡沫的故事，比只喊"未来已来"更有说服力。**

### 5. 四个反转 = 四个记忆点

- Loop ≠ 24/7 无人值守 → 它可能错得更贵（blast radius 更大）
- Graph ≠ 又一个 agent 框架 → 是工程范式（vs 实现工具）
- 五层 ≠ 年度替换 → 是同一时间同时需要
- 上升 ≠ 变简单 → 每一层都有自己的失败面，跟着往上爬

## 它和"一人公司"主题是同一件事的两面

最关键的一点：这条故事线天然是一把**深度标尺**。五层不只是"领域注意力怎么走"，它也能读成
**一个人能往深里走到哪**：

- **依赖现成** = 停在 prompt / context 层，用别人搭好的 harness（Claude Code、Cursor 这类）。
- **自己做** = 爬上去自己搭 harness，把 loop / graph 的灵活性收进来（DSH 就是这条路的落点）。

于是"一人公司要掌握到多深"这个主题，和五层故事线是**同一件事的两面**：
故事线给"路有哪几段"，主题问"一个人该走到哪一段、自己搭还是借现成的"。
这大概率就是 talk 要把两者焊在一起的那个焊点。
