# 讲稿与术语规范

- **PPT 生产素材**（`ppt-text-v1.md`）——**给 AI Agent 生成 PPT 用**：23 页，每页含 上屏文字（标题/副题/正文）+ 强调/金句 + 视觉建议 + 讲者备注 + 转场 + 素材来源。
- **页面内容（上屏文字 + 讲点素材）**在 `../03_outline/` 四个内容文件里——内容源。每节 = 一页：上屏文字 + 讲点（目的 / 讲点 / 金句 / 通俗例子 / 转场 / 素材来源）。
- **口语讲稿**（`talk-v1.md`）仅作 speaker notes 备用，非交付物。
- **术语规范**（PPT 上保留英文的术语，中文作口播参考）：

| 英文（上屏） | 中文表达参考（口播可讲） |
|---|---|
| prompt / context / harness / loop / graph engineering | 提示 / 上下文 / 围栏（harness 建议直接保留）/ 循环 / 图 工程 |
| Agent = Model + Harness | 不译，公式上屏 |
| context rot | 不译，保留英文 |

| adapter / vendor | 适配器 / 供应商（标注英文） |
