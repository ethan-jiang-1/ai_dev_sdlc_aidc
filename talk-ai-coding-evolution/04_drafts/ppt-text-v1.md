## 0.1 这是什么（背景，不用上屏）

- 一场 **45 分钟中文演讲**（硬上限 50 min），题目《**OPC 航海指南：OPC 与 Harness，AI 协作之道**》。
- **OPC = One Person Company（一人公司）**。主题：一个人开公司，要把 AI Coding 掌握到多深？依赖现成还是自己做？
- 听众：懂 AI coding 的程序员 / 产品经理 / 投资人。基调：通俗易懂、抓要害、引发共鸣。

## 0.2 核心立场（转场逻辑靠它，不用上屏）

1. AI Coding 工程注意力五级跳迁：**Prompt → Context → Harness → Loop → Graph**。
2. 驱动机制：模型越强，单次交互边际收益越低，杠杆点越往上移；**叠加，不是替代**。
3. 五层讲完，**根本还是 harness**（Agent = Model + Harness，harness 是承重墙）。
4. harness 这一格：**固定 vs 灵活**。立场：不是"别用现成"，是"别只能现成"。
5. 落点：**DSH（DeepSeek Harness）**；金句 **装自己的，借现成的**。

## 0.3 五层定义（备用，供你理解，不用上屏）

| 层 | 一句话定义 | 人的角色 |
|---|---|---|
| Prompt engineering | 把"我该对模型说什么"工程化——提示词是行为控制面，不是系统本身 | 说话者 |
| Context engineering | 把"模型此刻该看到什么"工程化 | 策展者 |
| Harness engineering | 把"模型在什么系统里跑"工程化——权限、沙箱、工具、验证、trace、CI | 环境工程师 |
| Loop engineering | 把"反馈"连成循环——模型越强越能"知错改错"，反馈得当就不断输出更好结果 | 控制流作者 |
| Graph engineering | 把"多个 agent 怎么被编排"工程化——用 workflow / DAG 控制乱发挥，换可靠结果 | 编排者 |

  - Claude Code 沙箱双重隔离；Copilot 云端沙箱
  - "Start with the simplest viable system." —— Anthropic
- 结论：绝大多数人，应从现成开始（底部，强调）

**不上屏**
