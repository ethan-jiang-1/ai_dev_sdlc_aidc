# AI-Native 软件研发组织 Talk

本文件统一 `talk-ai-coding-evolution-org-sdlc/` 内部讨论和制作使用的语言。它只服务这场软件 SDLC talk，不定义仓库其他目录或其他组织类型的术语。

## 页面构成

**画布**：
整页最底层、由 PowerPoint 统一产生的固定纸白表面。所有页面共享同一画布，视觉资产不能带入可察觉的异色背景。
_Avoid_: 背景、底图（当实际指整页底色时）

**页面主体**：
一页中用于讲清核心关系或状态的主要内容区域，可以由 Image 2 资产、PowerPoint 可编辑结构或两者共同构成。
_Avoid_: body、配图（当它实际承担主要表达时）

**文字层**：
由 PowerPoint 渲染、供观众准确阅读的页面文案与精确标签。
_Avoid_: 图中文字（当它实际指 PowerPoint 文字时）

**底图**：
真正铺满整页、位于文字层下方的图像资产。只在图像确实覆盖整个画布，且纸白区域与画布无缝一致时使用这个词。
_Avoid_: 图片、视觉主体（当图像并未铺满整页时）

## Image 2 采用原则

**表达收益**：
Image 2 对页面主体的解释力、空间感或记忆点带来的明显提升。是否使用 Image 2 只由表达收益决定，不由封面、章节页或普通页等页面身份决定。
_Avoid_: 重要页配图、封面必须有图

**主动比较**：
当原生图元虽然能画出内容，却会退化成框、箭头、卡片与标签堆积时，同时制作或评估生成式图文主体方案。
_Avoid_: PowerPoint 做不了才用 Image 2

**图源分界**：
页面若主要依靠标题、正文、数字、表格、日志或少量精确关系成立，使用 PowerPoint 直接呈现；页面一旦需要场景、对象、空间、材质、视觉隐喻或图文融合来辅助理解，优先由 Image 2 生成完整页面主体。这里的“图源”指承担解释任务的视觉来源，不是装饰图片。
_Avoid_: 用大量 PowerPoint 基础图元模拟一幅图、生成一张插画再用 PowerPoint 拼装其内部关系

## 生成视觉语言

**Visual Master Language**：
所有 Image 2 生成主体共同使用的母语，当前固定为「工程素描 + 编辑标注」。它规定线条、材质、颜色职责、空间方式和禁区；页面可以根据任务切换剖面、连续叙事或工件拼贴，但不能切换成另一套画风。
_Avoid_: 每页一种风格、实体纸模、建筑模型

**工程素描 + 编辑标注**：
以石墨铅笔和技术针管笔组织准确轮廓，保留少量构造线、擦除痕迹、剖面线与推敲痕迹；珊瑚红、青绿和金黄只以克制的彩色铅笔或淡墨批注出现。它不是艺术静物素描，也不是随意白板涂鸦。
_Avoid_: 3D 玩具、黏土或塑料模型、微缩建筑、等距模型、棚拍柔光、景深、悬浮阴影、复古插画

**视觉方言**：
同一 Visual Master Language 针对不同页面任务采用的句法：结构剖面素描用于内部机制，连续叙事素描用于因果和状态变化，工件拼贴素描用于证据链与责任痕迹。方言可以改变构图，不能改变线条、颜色语义和纸面关系。
_Avoid_: 独立主题风格

## 页面主体实现

**原生主体**：
主要由 PowerPoint 或 Graphviz 的可编辑结构组成的页面主体，适合精确关系、数据、拓扑和时序。
_Avoid_: 纯 PPT 页、普通页

**生成主体**：
主要由 Image 2 资产承担解释任务的页面主体，图像可以同时包含场景、空间、视觉隐喻与主体内嵌文字。
_Avoid_: 配图、插画（当资产实际承担核心解释时）

**混合主体**：
Image 2 负责丰富的图文构成与感知关系，PowerPoint 或 Graphviz 负责页面文案和精确关系；两部分共同完成一个页面结论。
_Avoid_: 图片加文字、图旁说明

**生成式图文主体**：
Image 2 把图像、空间、局部说明和视觉隐喻合成为一个整体的页面主体，适合原生图元难以自然表达的复杂定性关系。
_Avoid_: 装饰图、气氛图

## 文字归属

**页面文案**：
全篇需要统一排版和稳定复用的主标题、副标题、眉题、强调句、页码与固定术语，由文字层承载。
_Avoid_: 主体内嵌文字

**主体内嵌文字**：
与生成式图文主体的场景、对象或空间关系不可分割的标签、短语或一句简短说明，可以由 Image 2 生成。它必须在演示距离下直接读清；连续段落属于页面文案。进入样片前必须逐字校对，错误时重新生成或改回文字层。
_Avoid_: 页面文案、装饰文字

**内生图文优先**：
当文字、引线、标注与生成主体之间存在覆盖、穿插、贴合或空间依赖时，由 Image 2 在同一次构图中完成图文排布。PowerPoint 不在生成主体上补丁式覆盖标签；需要保持统一的页面文案仍放在主体之外的文字层。
_Avoid_: 先生成无字主体，再凭目测把 PowerPoint 标签盖在图上

**字体同源**：
主体内嵌文字与 PowerPoint 文字层使用同一套无衬线字体语言。中文以 `Hiragino Sans GB` 为参照，英文以 `Helvetica Neue` 为参照；素描感来自线条和构造痕迹，不来自手写字形。
_Avoid_: 手写批注体、书法体、漫画体、每张图一种字体

## 画布衔接

**无缝嵌入**：
生成资产以透明或边缘匹配的方式进入固定纸白画布，观众看不出独立矩形、残留底色或页间色差。
_Avoid_: 近似白底、图片白底

## 关系精度

**精确关系**：
一旦画错就会改变页面结论的工件顺序、门禁位置、责任归属、因果方向、数字、引用、拓扑与日志时序，由可编辑结构承载。
_Avoid_: 感知关系

**感知关系**：
用于让观众快速感到拥塞、速度、压迫、闭环、边界或材质的定性关系，可以由 Image 2 组织和强化。
_Avoid_: 精确关系
