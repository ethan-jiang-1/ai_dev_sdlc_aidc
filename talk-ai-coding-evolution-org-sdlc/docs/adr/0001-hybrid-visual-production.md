# 用生成式图文主体补足原生图元表达

这套 50 页 talk 采用固定纸白画布，并逐页在原生主体、生成主体和混合主体中选择。应用“图源分界”：页面若主要依靠文字、数字、表格、日志和少量精确关系成立，由 PowerPoint 直接呈现；一旦需要场景、对象、空间、材质、视觉隐喻或图文融合来解释，优先把完整视觉主体交给 Image 2。页面文案保持 PowerPoint 统一渲染；与生成场景存在空间依赖的短标签由 Image 2 内生构图并逐字核对。生成资产必须无缝嵌入纸白画布。这个选择在表达丰富度、全篇一致性、事实精度和后续可修改性之间取得平衡。
