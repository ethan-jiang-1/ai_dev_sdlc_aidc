# P1 与 P4 的主体路线改判

P1 封面与 P4 五层预告在 v0.15 前均为原生主体。用户 REVIEW 否决了 P1 的原生六点环路——它是抽象图示，三秒内读不出「一条价值流」；同时指出 P4 不能把五层与 SDLC 六阶段并置：五层是随模型能力增长、每层包含前一层的叠加（当下承重的是 harness，loop / graph 是把它用得更稳的进阶用法），把五根柱子立在同一条 SDLC 线上正是要消灭的误读。两页因此改为 Image 2 生成主体：P1 用单线价值流剖面表达暗线，P4 用包含关系剖面与增长来历表达五层的真实关系。这次改判不是回到「封面必须有图」的旧逻辑，而是表达收益证据变化——原生图元在这两页被证明读不出页面结论，符合「是否用 Image 2 只看表达收益」的既定原则。页面文案仍由 PowerPoint 文字层渲染，生成资产预留标题安全区并逐字核对。
