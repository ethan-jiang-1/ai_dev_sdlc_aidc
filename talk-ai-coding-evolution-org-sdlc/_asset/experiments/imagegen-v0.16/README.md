# GPT Image 2 v0.16 REVIEW 修订实验与成片资产

本轮在 v0.15 用户 REVIEW 反馈基础上，先生成一张风格基准图，再以该图作为风格参考输入生成 P1、P4、P7、P11、P12、P16、P18、P19、P21、P23、P29、P31、P33 的新主体。P11、P12、P18 的首轮结果经过定向编辑修正，最终版本已进入 v0.16 PPTX；其余页面使用首轮通过的成片资产。

生成配置：工作区 `.env` 中的 Packy 入口 `https://www.packyapi.ai/v1`，`gpt-image-2`，`2048x1152`，`high`。生成时使用 `imagegen` skill 随附的 `image_gen.py`；原始提示词保存在本目录，密钥只从工作区 `.env` 读取，不落盘。

全批次必须遵守：匿名人物只画手、侧面或背面；单一连续场景与单一主方向；门禁物理落在路径上；珊瑚红最多两处；青绿只表示运行或反馈路径；金黄只表示工件、签名或证据；除提示词逐字列出的文字外不出现任何可读字符；上方保留 PowerPoint 标题安全带。

`generated/` 同时保存原始生成图与纸白融合成片；PPTX 使用的最终选择、逐页处置和 QA 结论见 `../../09-v0.16-change-review-ledger.md`。
