# GPT Image 2 v0.14 图源分界实验

本轮采用“图源分界”：文字、数字、表格、日志和少量精确关系页由 PowerPoint 直接呈现；一旦页面需要场景、对象、空间、材质、视觉隐喻或图文融合，完整页面主体优先由 GPT Image 2 生成。

首批升级页为 P5、P25、P32、P41、P44、P45、P49。它们原先已经依赖边界、包围、分流、承重、路径、撞击或收束等图像概念，却由 PowerPoint 基础图元模拟，因而与既有 Image 2 强页形成质量断层。

生成配置：Packy 主入口，`gpt-image-2`，`2048x1152`，`high`。原始提示词在 `prompts.jsonl`；密钥不落盘。生成结果必须经过逐字检查和画布融合，再决定是否进入 PPTX。

P49 首次渲染中“责任人”在演示距离下过淡。`p49-edit-v2.txt` 记录定向编辑约束：只提高该标签与岗位轮廓的对比度，其余构图、关系、文字和色彩语义保持不变。
