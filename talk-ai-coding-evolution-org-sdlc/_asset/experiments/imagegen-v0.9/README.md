# GPT Image 2 图文主体实验（v0.9）

本轮只为 P8 与 P20 生成页面主体。P1 与 P42 使用 PowerPoint 原生主体。

- 主入口：Packy；MICU 仅在主入口失败时备用。
- 模型：`gpt-image-2`。
- 页面画布：固定 `#F7F8F5`；生成资产先使用纯蓝键控底，再提取透明通道，避免近似白底造成页间色差。
- 页面文案：标题、副标题、眉题、强调句与关键结论由 PowerPoint 文字层渲染。
- 主体内嵌文字：P8、P20 各保留少量与空间结构不可分的短标签，并逐字核对。
- 精确关系：P8 的“排队 / 审查不足”和 P20 的“圈住 / 拦住 / 看清”由 PowerPoint 可编辑层表达。

最终入选资产、提示词和透明边缘检查结果保存在本目录。密钥只在运行时从工作区 `.env` 读取，不写入资产或 PPTX。
