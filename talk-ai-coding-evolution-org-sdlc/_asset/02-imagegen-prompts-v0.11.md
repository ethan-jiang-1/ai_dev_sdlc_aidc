# Image 2 生产 brief（v0.11）

> 历史样片 brief：本文件记录 v0.11 怎样验证内生图文与字体同源。当前通用术语与规则见 `../CONTEXT.md`，当前生产状态和资产入口见 `../CURRENT.md` 与 `experiments/imagegen-v0.13/`、`experiments/imagegen-v0.14/`。

Visual Master Language 延续 v0.10 的「工程素描 + 编辑标注」，v0.11 新增两条优先规则：内生图文优先、字体同源。

## 图文一体边界

- 文字、引线、标注若与生成主体存在覆盖、穿插、贴合或共同占位，由 Image 2 在同一次构图中完成。
- PowerPoint 只承载主体之外的主标题、副标题、眉题、强调句、页码与固定术语，不在生成主体上补丁式覆盖标签、引线或色块。
- 主体内的所有中文、英文、指向关系和留白必须作为一个整体 REVIEW；错字、错指、穿字或不一致时回到 Image 2 修改。

## 字体同源

- 中文以 PowerPoint 的 `Hiragino Sans GB` 为视觉参照，英文以 `Helvetica Neue` 为视觉参照。
- 一级标签使用半粗无衬线，二级说明使用常规无衬线，字距为 0。
- 素描感来自石墨线、构造线、擦改痕迹和引线，不来自手写字形。
- 禁止手写批注体、书法体、漫画体、粉笔字、马克笔字、装饰字体和每张图不同的字形。
- 生产时把实际 PowerPoint 渲染页作为第二张字体参考图输入 Image 2，而不只在提示词中写字体名。

## v0.11 样片分工

| 页面 | Image 2 承担 | PowerPoint 承担 |
|---|---|---|
| P8 | 宽产出、控制容量、排队、审查不足及其标签和引线 | 标题、副标题、眉题、阶段轨道 |
| P20 | 系统剖面、圈住 / 拦住 / 看清及二级说明和引线 | 标题、副标题、眉题、阶段轨道 |

最终提示词、字体参考迭代和入选透明资产位于 `experiments/imagegen-v0.11/`。Packy 为主入口，MICU 为备用。

## REVIEW 门槛

- 内嵌文字逐字正确，指向正确，演示距离下可读。
- 内嵌文字和 PowerPoint 文字层属于同一套无衬线字体系统。
- 一级 / 二级文字层级、字重、颜色职责在 P8/P20 之间一致。
- Image 2 内部不存在文字与图形 overlap；PowerPoint 不在主体上做覆盖式修补。
- 透明边缘、纸白画布、颜色语义和工程素描语言继续满足 v0.10 门槛。
