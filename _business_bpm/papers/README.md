## 今后引用策略

**主引用 #1**：`papers/apm-manifesto/`。它是这个子领域目前**最高权威级别的文献**——顶级期刊 + 最负盛名的学术研讨会背书 + 全明星作者群。说"Agentic BPM 的 Framed Autonomy"就引用这篇。

**辅助引用 #2**：如果需要引用 A-BPMS 的五层架构或自主连续体。

**辅助引用 #3**：如果需要引用 Framed Autonomy 的数学定义或形式化基础。
