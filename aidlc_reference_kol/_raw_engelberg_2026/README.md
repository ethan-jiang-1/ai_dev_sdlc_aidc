## 为什么这个目录值得单独存在

Engelberg 不只是 Deer Valley 的续集。它是 **agentic engineering 从实验到生产的转折点的最确切证据**。

- 五个月前 Deer Valley 还在问"这可能是什么"——Engelberg 没有人问这个问题了
- "Harness Engineering" 这个术语在 Deer Valley 时还不存在
- Token 成本、组织设计、Galaxy Brain 辩论——这些都是只有在**真正跑在生产环境中**才会浮现的问题
