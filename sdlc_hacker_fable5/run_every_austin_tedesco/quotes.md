# Austin Tedesco：洞察摘录

## 关键言辞

> “Fable 5 demands a very different way of approaching knowledge work.”

- 这句很好地说明了 Austin 不是把 Fable 5 当成更贵的聊天模型。
- 在他这里，变化发生在任务定义方式，而不是 prompt 花活。

> “Austin’s reserved Fable 5 for ‘rocket launcher’ projects that can run for four-plus hours.”

- 这是非常具体的任务边界。
- 对资料库来说，这种边界比“更强”“更聪明”有价值得多。

> “With the model, he typically uses compound engineering’s LFG flow, which has the agent brainstorm, plan, work, review, and repeat.”

- 这句把 Fable 5 接到了可复用的流程层，而不只是单次体验。

## 总结判断

- Austin 是很典型的非模型公司、应用型使用者样本。
- 他的材料尤其适合回答一个问题：Fable 5 什么时候真的值得开，什么时候不值得。
