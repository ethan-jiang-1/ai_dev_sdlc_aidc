## 八、逐页讲法 [不上屏]（讲法只在本节，04 里没有）

> 讲者用；**不进渲染**。带「口播」的是可以照着说的话。

| 页 | 讲法 |
|---|---|
| **P1** | 封面说的是改善方向，不是不出错的保证。开场说：**"今天只回答一个问题——同一个模型，为什么在别人手里好用，在你手里糊涂？"** |
| **P2** | **约 30 秒口播，不要念屏。** 讲完停一秒，再说："这时候你会怪模型——先别怪。" 这一页不出任何术语；**例子只挑一个讲，别都讲。** |
| **P3** | 念完**停 3–5 秒**，问「**你中过哪一条？不用说出来**」（房间可能有上级在场：不点名、不举手）。**不做这一步，后面五件事没地方挂**；**全场最容易超时的一页**；**"还可能这么说"的候选句，挑听众最可能点头的那句换上去。** |
| **P4** | 先认账"模型确实一直在变强"，再给落点。**这是全场唯一的趋势判断，也是听众最可能的抵抗点**——不回答，整场必要性立不住；**三种反驳先替他们说出来，再答。** |
| **P5** | `harness` **全场只在这里和结尾出现两次**，其余各页说"模型外面那一圈"。**口播两句就够**：① 比喻「**脑子继续换，身体不用每次重新造**」——**这是中文界的提炼，不是官方原话**；② 旁证「**上个月有家厂商干脆把这一圈做成了产品开源出来，卖点就是一行代码 + 随便换模型**」。**不点产品名、不报任何数字**。口播可补原意：模型给智能，那一圈让智能真的能干活。**说完"那一圈"要接着问一句"里头有什么"——交代规矩、给资料、给工具、定步骤、做完检查，这五样一说出来听众都见过** |
| **P6** | **紧跟 P5 出——学完公式马上知道影响面**：不只管智能体，写文章／写代码／做报价都行——**只要要反复做、要质量、要稳**。**别展开讲**（这是给听众的"原来如此"，不是新知识点）；口播一句就够："你们写周报、改方案，是不是也要反复打磨？一样的道理。" |
| **P7** | **全片主线页**——先把"信噪比"说成人话（**有用的多、没用的少**），再给"**按图索骥**"；**五件事只出名与顺序，不逐条念**（与 P3 五种症状同号对应）；**收到上一页**："那个比例，就靠这五件事调上去"。别当技术词讲。**多说一句"少即是多"，这页就立住了** |
| **P8** | 对应症状 ①。**别讲"上下文窗口"这类词**；"上下文"这个词只在本页命名一次，之后才可沿用 |
| **P9** | **上屏一律说"把老手脑子里的东西写出来"**；"隐性知识显性化"是本目录内部名，**不上屏、不进讲稿**。这里要补一个听众一听就"对对对就是这样"的老手坑（缺口见 `../CURRENT.md`） |
| **P10** | 对应症状 ③（含"碰了不该碰的"）。**不说"权限／沙箱"** |
| **P11** | **"来回兜圈子"是最高频的失败**——只口播，**不上屏任何百分比** |
| **P12** | **全场最重要的一页**。必须说清两件事：① **代码就是程序的写法，这里用程序查明确的规则，只证明查过的部分**；② **写不用你写，要求和业务接受要有人负责**。数字（验证类失败占比等）**不上屏**。下一页回答"那谁写" |
| **P13** | **这页只有 30 秒，但不讲不行**——不讲，"让程序查"对技术一般的听众就落不了地。依据是 Anthropic 2026 的"生成与评判分开"，但**不上屏、不署名**（署名只留给 P4／P5）。口播可换成白话：**"不能只听它说做好了，要按事先的要求看证据；风险高，再找独立的人复核"** |
| **B1** | 念完**静默 5–8 秒** |
| **P14** | **这页回答的是"搭多厚"，不是"搭不搭"**；不要讲成"风险评估"；**四格每格一行例；同格可替换的例子随听众行业挑。**<br>**先把"厚薄"落成可数的东西——就是加几道关**：两个判据各认领一道关（**赔得起吗 → 要不要"拦"；多久能发现 → 要不要"看"**）。**四格的答案要能横向比（不加／一道／一道／两道）**，别让听众听成四句互不相干的话——**这正是上一版的毛病。** |
| **P15** | **不许讲成"越复杂越高级"**；第 3–4 档最容易上头。"工作流／智能体"只在本页命名一次；**每档配一个日常场景**。<br>**两条轴别混**：P14 算的是关（厚薄），P15 看的是谁在管（归谁）。<br>**主职是"合起来用"**（现成的别重搭／自己搭的定验收），**另加一句防混** |
| **B2** | 念完**静默 5–8 秒** |
| **P16** | **这页比四档更容易被跳过，不能省**——省了本场就变成劝人上自动化。第 3 条"先别"要**从根上说**，**分两种**：**1. 你不熟，判不出对错**（判不出对错，构建、打磨、验证一件也做不了）；**2. 你自己还没定下来**——**判得出对错，不等于政策已经定了**，**政策没定就别指望它替你定**（讲法纪律第 14 条）。这也顺带解释了**为什么练手要挑自己熟的活**（与手册 HP5 的四个条件对齐） |
| **P17** | 第 2 条要**明确接回 P13**，否则听众回去还是不知道检查从哪来。**口播可点一句**：该试的不是"哪个模型更强"，是**你这件事交给这套组合要花多少、成不成** |
| **P18** | `harness` 全场第二次、也是最后一次上屏。一句话收，**不再展开定义**；**可选里是"带走的三件东西"，看时间决定给不给。** |
