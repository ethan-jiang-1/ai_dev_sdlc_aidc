# Phase 1: 叙事大纲

> 本阶段目标：找到那个 5 秒能讲清的核心隐喻，用可证伪的公式锁定论证方向，画出叙事弧线。

## 输入

`research/source-synthesis.md`（Phase 0 产出）

## 产出

`outline.md`，包含以下章节：

### 1. Core Metaphor（核心隐喻）
- 2-3 个候选，每个一句话描述 + 为什么适合
- 用户选一个

### 2. Core Formula（核心公式）
- A + B = C 形式，可证伪
- 例：`Readable Data + Managed Agents = AI Adoption`

### 3. Narrative Arc（叙事弧线）
- 从观众现状 → 认知颠覆 → 新框架 → 行动号召的完整路径
- 参考 `_ppt_framework_v1/02_content_design/presets/block-arc-catalog.md`

### 4. Block 结构
按叙事目的分组的 slide 集合（通常 3-5 个 Block）：

```
Block 1: [叙事目的] — 回答观众的什么问题？
  - Slide 1.x: [一句话 claim]
  - Slide 1.y: [一句话 claim]
  - ...

Block 2: [叙事目的]
  - ...

...
```

### 5. Slide Map（完整 slide 清单）
每张 slide 的：
- 序号
- Block 归属
- VISUAL TYPE（Title / Concept Split / Evidence / Framework / Section Divider / Closer）
- 一句话 CLAIM（核心主张，必须是完整的、可争论的句子）

## 目标页数

`--standard` tier: **15-20 slides**（对应 ~40 分钟演讲）

## ⛔ 闸门

Phase 1 完成标准：
- [ ] 隐喻已被用户确认（不是"差不多"，是"就是它"）
- [ ] 公式可证伪
- [ ] 叙事弧线覆盖完整旅程
- [ ] 每张 slide 的 claim 是可争论的完整句子
- [ ] Slide 总数在 15-20 范围内
- [ ] 用户确认：这就是我要讲的故事
