**前置要求**（开讲前通知）：带一个你真实在跑（或想跑）的 agent 任务；有条件的带笔记本与一个可回滚的练习分支——练习 2 要真的埋一个错误。

## 纪律

- 学员版不出现内部路径与层级命名；来源以产品名＋署名原话呈现。
- 每题产出可核对（讲者卡给判定标准）；学员写不完的，模板本身是带走的作业。
- 练习操作全部在**可回滚环境**做；不碰生产分支。

## 本轮同步与制作边界

2026-10-04 同步：三题嵌 **B14/B19/B33**（B16 拆页后新编号），时长 8/7/8 分钟，整体 90 分钟预算未改。练习 2 增「反馈闭环补一行」步骤（原始结果位置＋消费者＋去向，现场只补一行、完整闭环作回去演练）；练习 3 续跑面增「反馈准入与实际消费」证据项。新增授权按交接面核适用项，不把纸面填写当上线批准；纸面填完不记已部署、未实做保持待演练。负例题标题与判语改为具体检查行为，不靠颜色代替判定。
