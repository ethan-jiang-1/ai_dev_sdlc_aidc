# manual/ — 听众带走的操作件

**定位**：两场 Keynote 的配套落地操作件《图工程与多智能体协作治理手册》（单文件双篇）。

**结构**：
- **上篇（通识篇 / 审计层）**：企业多 Agent 项目健康度自检表、伪群聊模式识别、HITL 三道门禁把关卡。
- **下篇（操作篇 / 工程层）**：双轨元图代码模板（LangGraph / Temporal）、强类型 Schema 定义规范、Failure Envelope 与子图切片 SOP、机器级 Hook 防御脚本。

**权威关系**：
- Keynote 是手册的叙事上游，手册是 Keynote 的实操落地；
- 两场文稿收尾页全部指向本手册，规程细节不在文稿中重复占用页面空间。
