## 关键事实

1. Vercel 官方文章标题直接说明：
   - Stripe 用 v0 在一次长途飞行中做出了 production GTM value calculator
2. 正文说明：
   - Mario Braz 在无正式工程背景下，用 v0 原型并部署了该应用
   - 首版是 web-based、mobile-friendly，并 ready to deploy
3. 文章把结果描述为 customer-facing / GTM-facing value calculator，并明确说它缓解了原先 spreadsheet workflow 的高摩擦问题。
4. 文章给出 adoption outcome：
   - average weekly internal users 从 23 提升到 92
   - 对应 `288%` increase in adoption
5. 文章给出效率 outcome：
   - time to generate initial value hypotheses `decreased by ~80%`
   - 每周约节省 `30–40 hours` 的 FTE time
6. 文章还给出组织扩散信号：
   - Solution Architects 开始做自己的 demos
   - Product Managers 用它做 prototypes to guide engineering
