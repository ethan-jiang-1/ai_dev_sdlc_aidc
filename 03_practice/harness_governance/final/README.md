## 命名与生长规则（防指代歧义）

- 续用**主题全局编号**（03、04、05……）；research/ 封存 01/02 系，两层不撞号；
- 文件名语义化（backbone / manual / ……）；**不用字母后缀**（01a 式 = research/ 证据档案专属惯例，final/ 不复用）；
- 04 超 ~1000 行按域拆 `manual/` 子目录（artifacts / loops / rhythms……，具名不用号）；模板类内容先以代码块进 04，需要独立文件时再立 05；
- 引用写法："final/03 §2.3" / "research/01a B8" 式（层前缀 + 编号 + 节号），禁用裸编号指代。
