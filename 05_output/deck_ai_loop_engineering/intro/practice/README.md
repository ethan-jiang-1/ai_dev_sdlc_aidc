## 纪律

- 学员版**不出现**内部路径、研究层/实践层命名与代号；来源以产品名＋署名原话呈现。
- 每题答案可核对（讲者卡给定），不开放辩论式无锚答案。
- 练习材料里的数值均为教学示意，不是厂商实测；讲者卡标注。
