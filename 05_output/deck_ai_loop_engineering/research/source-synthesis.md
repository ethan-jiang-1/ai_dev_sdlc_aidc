# Phase 0：素材合成

信号从成稿抽，不从回源档案另起主张。逐字引句与票数留在研究层。本文件只回答：这场 keynote 可以讲什么、不能讲什么、对客要怎么说。

实践层确认时留下的四处表述，在这里收成讲法，不回改 backbone：

| 原位置 | 讲法 |
|---|---|
| 调度（backbone §2） | 先讲两件抽象的事：进度在对话外面；下一轮有触发。产品名放讲者备注 |
| 自主度（§3） | 缺口改成行动：不按轮次授权，按事件授权 |
| 接口（§5） | 一句话依赖，不讲目录和规程 |
| 裁判 | 合成一页「谁有权说完成」，不拆成五页选型 |

## 1. 可以上屏的信号

### 1.1 定义

- Loop 层管「怎么回头」：上次结果改变下次行动。四要素是触发、验证、停止条件、记忆。
- 硬判据一：停止不看上次结果，那是重试。
- 硬判据二：单次不受控，循环是错误复制机。
- 权威表述：[`landscape.md`](../../../02_research/ai_loop_engineering/result/landscape.md) §3.1；展开在 backbone §0。

### 1.2 命名，点到为止

- 专名出现在 2026-06。词源两支是热度碎片，定义来自事后的工程化写作。
- 能讲的共识只有一句：用系统替人把一轮跑完。
- 层数和最外层互相不兼容。实践主题因此叫循环治理，不叫 loop engineering。研究层保留运动名。
- 对客不展开第六人名单。需要人名时只用已经有定义文本的：Osmani（命名）、Runkle（四环，外延不同）、Ng（方法论三环）。

### 1.3 停止

- 敌人：提前宣告完成。
- 三件：机器可核的门；硬性熔断；验收与干活分离。
- 熔断是资源停机，不是验收。模型说完成，不是证据。
- 产出过闸不等于业务结果达成。结果当前看不见，就留给人，不自动标成成功。

### 1.4 谁说完成

五极并成一个设计选择，按强弱讲，不按产品讲：

1. 干活的一方自己宣布——最弱，和提前完成是同一件事。
2. 一份外置清单逐条判定。
3. 另一个角色只核硬规则。
4. 审批方判定，干活方不给自己发通行证。
5. 人的判断——留在品味、含糊意图和最终验收，不留在每一步。

保护条款只留一句：检查不能被正在干活的一方改掉。

### 1.5 调度

- 单个有界任务不必有调度器。
- 长程才需要两种已观察到的形态：进度外置；触发器决定何时再跑。
- 不能讲成「人工审批已经从组织里消失」。
- 四列空，对客用工作语言，不用研究黑话：谁批准过这次范围、优先级谁改过、卡在等人还是等依赖、多项工作谁验收了。邻近物存在，这四列没有同时出现在一张已复核的表上。

### 1.6 人站在哪

- 有位置词，没有轮次刻度。两套四级和一条官方路径都是分类，不能换成「成熟度第几级」。
- 行动指引：升档看动作类别、关键歧义、拒绝之后怎么办、人是否接得住。不看「已经跑了几轮」。
- 许可证：门会在错的时候变红，才把人从每一轮撤走。
- 具体拒绝次数、超时分钟、默认轮数不上屏当行业数字。

### 1.7 何时人看，何时不要循环

- 人留在：高风险动作、意图不清楚、最终验收、熔断之后的接手。
- 先不要上：一次就做完的小任务；单次运行还不受控；还没有真实的失控，只是想加一套循环脚手架。

### 1.8 三层，一句话

Harness 托住一次运行。Loop 组织多轮。变更工件可以当循环的输入和验收依据，不是循环的对立面。Graph（多个 agent 怎么编排）不在这场里。

### 1.9 goal 只讲到控制接口

- 循环要有一句写得出检查的完成条件，否决权在干活的一方之外。
- 写不出检查句时，不要把探索冒充成机器可判的完成。
- 构造方法和调优数在 `agent_goal_eval`，这场不讲成第二门课。

### 1.10 失败模式（加深档用）

backbone §0.2 的十种：重试冒充循环、错误复制机、一次做完所有、提前宣告完成、未验证就标完成、没有进度盘、自主度超前、操纵裁判、授权漂到新动作或升级走不通、资源停机冒充验收。

标准档不单列十行。它们分别落进判据、停止、调度、升档四页。

## 3. 叙事可用的张力

这些张力都已在成稿里，不是为了讲稿新造的：

1. **词很热，定义没收敛。** 所以开场用问题，不用运动口号。
2. **跑得动，看不清。** 执行和停止的机制有了，多项工作的四列账没有。
3. **位置有了，刻度没有。** 观众会要一张「几轮升级」的表。讲稿的任务是把这张表换成事件门。
4. **灯与人。** 人撤多远，由已知的错会不会让灯变红决定，不由模型宣传决定。
5. **还不能说。** 边界收进收束的第二句，不单开一页清单。
