# 循环交接手册（Loop Handover Manual）

> 把哪个决定交给循环，交之前配什么护栏，它说做完了凭什么放行。两场 Loop Engineering talk 的听众带走的操作件。

## 一、这是什么、不是什么

- **是现场手册**：按「时刻」组织。你正在某个具体的时刻——想把一个决定交给循环、想升一档、它说做完了、它停了——翻到那一章，照着查、照着配、照着走。
- **不是课程**：不从第一页读到最后一页，没有练习和进度。
- **不是论证**：为什么这样做，talk 里讲过；手册只管怎么做、怎么查、坏了怎么办。
- **不是第二权威**：判定与规程的上游在研究层与实践层（见 [AGENTS.md](AGENTS.md) 速查表，维护者用）；本手册是它们的面向读者重组，重组处标注「本手册编排」。

## 二、一句话主张

**每一档都是一次交接：交出一个决定，换回一组护栏。学会选对档位，比爬到最高档重要。**

## 三、目录（按时刻）

| 章 | 你的时刻 | 内容 spine |
|---|---|---|
| [00 用法与状态语汇](00-用法与状态语汇.md) | 第一次拿到这本手册 | 怎么翻、参数锚约定、状态语汇表（什么最多能声称什么） |
| 01 要不要交给循环 | 有个任务，犹豫交不交 | 三问诊断＋反过度工程：单次小任务不建循环、完成条件写不成可观察句子就不硬跑 |
| 02 交动作 | 想减少逐动作审批 | 授权面划定：分级处置表、动作×目标×有效期、拒绝怎么回流、审批三动作 |
| 03 交续跑 | 想让它自己跑多轮到目标 | 目标三要素模板、裁判选型与保护、目标可枚举时上进度清单、熔断配置 |
| 04 交唤醒 | 想让它定时/按事件自己起跑 | 触发器选型、会话内与跨会话两种边界、取消传播与孤儿检查、无人值守变体的额外门槛 |
| 05 升一档 | 现在的档位跑稳了，想往上交 | 三项门禁（负例控制/裁判独立/熔断）＋控制路径演练——全书的铰链 |
| 06 它说做完了 | 回来了，它说「完成」 | 放行五接口：目标契约/环境证据/裁决协议/资源进度/跨次责任；产出与外部结果分账 |
| 07 它停了 | 它熔断/超时/停了，要接手 | 交接三路（硬拒/可批/阻塞）、两件事分记、退档信号 |
| 08 可选方向 | 听说多代理/自改很神 | 编排与元循环：局部已证、成熟度未证；高阶不是毕业要求 |
