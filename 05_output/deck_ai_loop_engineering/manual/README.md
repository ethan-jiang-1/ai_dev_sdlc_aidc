## 一句话主张

**每一档都是一次交接：交出一个决定，换回一组护栏。学会选对档位，比爬到最高档重要。**

## 三个上游与分工

| 上游 | 它管什么 | 手册取什么 |
|---|---|---|
| 研究层 landscape（§3.5 交接面） | 哪些交接面已有机制、哪些是空 | 高级篇各节的「这一档交什么、补什么」判定 |

## 状态

立项 2026-09-30，后续修订：**①加密度**——每节铸入「可抄之物」（授权面表、审批伪代码、goal 三轮教学走读、唤醒记录、演练记录、放行检查单、状态记录行）；**②移址**——按要求自 `05_output/manual_loop_handover/` 移入本目录；**③合册**——单文件双篇，卷首语汇与三本账为唯一权威；**④逐面与可审计边界**——`/goal`、`/loop`、动作审批分别核面，唤醒不自动证明审批或验收，`accepted` 必须人签认，六勾只进入验收；**⑤来源与参数纪律**——正文来源注使用具体一手文档名与可点 URL，版本锚与观测日期分开，示例数值不可抄生产，内部映射仅在文末 HTML 注释。当前验收与待定项以 [AGENTS.md·当前稿](AGENTS.md#当前稿进度权威) 为准。

**本轮操作性补齐**：高级一内嵌授权、责任与恢复字段；高级二内嵌 goal、约束、无进展、资源上限、裁判版本及失败交人契约，不依赖入门四；高级三内嵌调度器／worker／副作用取消记录，使用官方 deployment 形式而非自造 API。高级四门禁按要交出的面分流，高级七只建议人审、可回滚试行，不作安全保证。
