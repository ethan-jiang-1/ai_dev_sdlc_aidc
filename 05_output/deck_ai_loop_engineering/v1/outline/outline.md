# Outline v1：它说做完了

标准档 14 页，约 40 分钟。加深 10 页只在有人追问时用，不插进标准档的中间。

这一版改的是论证，不是配图。上一版把研究结论按题目摊开，听众听到的是清单。这一版只跟一件事：你离开之后它继续跑，你回来时它说做完了。整场回答你凭什么信。

## 1. 核心隐喻

**灯。**

绿灯只表示有人按了完成。你要信的是：同样的错，下一次会让这盏灯变红，而且按灯的不是写代码的那一方。

灯不是「循环」的图示。循环是灯会不会再亮、谁有权把它按绿、人还站不站在每一次按灯旁边。

## 2. 核心公式

```text
错了会红 × 停的时候看过上一轮 × 签字的不是干活的人 = 才可以把人从每一轮撤走
```

三个因子都是设计，不是模型的品德。缺一个，人就还在每一轮里。

这场不证明这样做更快、更好、更省人。它只划出「可以少看一轮」的条件。证明不了的话放在收束的一句里，不单开一页清单。

## 3. 叙事弧

听众已经让它自己跑过。开场不解释什么是代理。

```text
你回来，灯是绿的
  → 绿有两种便宜的来法
  → 要防的只有一件事：还没做完就宣布做完
  → 检查、熔断、签字是三件不同的东西
  → 长活才需要「下一轮从哪来」
  → 别人会问第几轮。没有这个数
  → 已知的错不会变红，人就留下
  → 你准许的是这盏灯
```

| 页 | 听众这时该明白的 |
|---|---|
| S01–S02 | 忙不是证据。绿也不是 |
| S03–S04 | 失败通常不是「它变坏了」，是完成被设计得太便宜 |
| S05–S06 | 停、通过、签字，三件事不能并成一句「它停了」 |
| S07–S08 | 一件事不必有调度。很多件事同时在跑，日志也不等于总账 |
| S09–S11 | 不要用轮次决定撤人。用灯会不会红、人接不接得住 |
| S12–S14 | 这一轮还不受控就先别循环。写不出检查就交给人。带回去的是灯 |

## 4. 标准档

每页只有一句能被复述的主张。证据和人名留在讲者备注。

**S01 · 封面**
它说做完了。

**S02 · 你回来的时候**
灯是绿的。你要问的是：这个错，下一次会不会让它变红。

**S03 · 两种便宜的绿**
一种是没看上一轮就又跑了。一种是干活的人自己把完成签了。

**S04 · 要防的那一件**
还没做完，就宣布做完。要拦住的就是这一下。

**S05 · 三件不要并成一件**
会变红的检查，是一回事。到点停了，是另一回事。谁签字，是第三件事。

**S06 · 谁可以签字**
干活的人自己签字，是最弱的。检查若能被干活的一方改掉，灯会学会对自己变绿。

**S07 · 短活不用调度**
一件边界清楚的事，不必有人专门安排下一轮。变长了，没做完的必须写在对话外面，而且下一轮得有一个触发。

**S08 · 日志不是总账**
它能续上，你仍可能不知道：谁批准的、优先级谁改的、卡在哪、谁验收的。

**S09 · 没有第 N 轮**
别人会要一个轮次。没有。看这一下危不危险、意图清不清楚、拒绝之后有没有人接。

**S10 · 许可证**
拿一个你已知的错去试。灯不变红，人就还站在每一轮里。

**S11 · 人留下的地方**
高风险、说不清的意图、最终收不收、熔断之后谁接手。

**S12 · 先有这一轮**
这一轮还拦不住已知的错，或这件事一次就做完，就不要让它自己开下一轮。

**S13 · 写不出那一句**
完成条件写不成一句能检查的话，就交给人。不要靠多跑几轮把它跑绿。

**S14 · 带回去**
你准许出去的是这盏灯，不是一个更聪明的模型。这场没有证明它因此更快或更好。

## 5. 加深档

不进标准档的顺序。有人追问再翻。

| 页 | 只回答这个追问 |
|---|---|
| E1 | 「loop engineering 这个词不就是定义吗？」三个已核对的外延互相不兼容。未复核的不出现。 |
| E2 | 「是不是先自动化、再自主、然后才有循环？」四个词可以叠在一起，不是一条阶段史。 |
| E3 | 「失败还有哪些？」十种失败都能对回上面某一页，没有第十一种主题。 |
| E4 | 「拒绝之后会怎样？」放行、等人、硬拒绝、升级。升级画在图上，边可能是断的。 |
| E5 | 「角色分开就够了吗？」检查和改动不能放在同一个可写的地方。该做却没做的，灯仍可能是绿的。 |
| E6 | 「到底哪些已经有办法？」执行、停止、这一下能不能做、这一次会话记得住，已经有公开的办法。空的是多项工作的那四列。 |
| E7 | 「我们的系统不是已经能自己续吗？」能续上，和有总账，不是一回事。 |
| E8 | 「外面那些四级，我们在第几级？」三套说法不能换算成一把尺子。 |
| E9 | 「目标本来就写不清，怎么办？」探索可以，由人看。不能把看不见的业务结果自动标成达成。 |
| E10 | 「回去第一步做什么？」先用已知的错试灯，再写停止要看上一轮，再把长活的进度拿出对话，最后才谈人离开每一轮。 |

## 6. 语言

投影用中文短句。loop、harness、goal、eval 可以出现在备注里，主张句不依赖它们。

运动名只在 E1。标准档不花一页解释 2026 年 6 月谁起的名字。那个事实是真的，但它会把一场决策讲成一场考据。

「轮数」不进 S05 的口播。S05 只说时间或连续拒绝到了上限：停了，不等于通过。别人追问第几轮，由 S09 回答：没有这个数。某一家自己的轮数上限留在备注。

## 7. 这一版故意拿掉的

- 用一页罗列「还不能说」。边界收进 S14 的第二句，细节留在备注。
- 用一页做三层架构图。S12 只留依赖：这一轮不受控，多轮就是错误复制。
- 把五类裁判拆开讲。S06 只留最弱的一极，和「检查不能被改」。
- 产品的次数、天数、默认轮数。备注里被问到再答「那是那一家的参数」。

## 8. 公式落在哪一页

| 因子 | 听众在哪一页听见 |
|---|---|
| 错了会红 | S02 提出问题，S10 用一个已知的错去试 |
| 停的时候看过上一轮 | S03 的第一种绿，S05 里「到点停了」不等于通过 |
| 签字的不是干活的人 | S03 的第二种绿，S06 |
| 才可以把人从每一轮撤走 | S09 拒绝用轮次，S10 灯不变红人就留下，S11 人留下的四个地方 |

S07 和 S08 不是第四个因子。它们回答的是：活变长了，下一轮从哪来，以及续得上不等于看得清。S12 是第一个因子的前提：这一轮还不会红，就还没有资格谈撤人。S13 是第三个因子落空的时候：写不出可检查的那一句，签字只能留给人。S14 把公式说回去，并带上这场证明不了的那一句。
