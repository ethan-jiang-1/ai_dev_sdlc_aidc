## 规则

1. **只摘不搬**：不整段复制上游正文；摘进来必须写清来源路径。
2. **必须标证据强度**：一手 / ⚠️ 厂商自述 / ⚠️ 降级取证 / 趋势级（写法见 `../CONTEXT.md`）。
3. **会漂移的值标观测日期**：星数、插件数、成本数字。
4. **口径不可比的两个数字不合成一个**。
5. 上游结论与本 talk 判断必须分开写；本 talk 的解释性结论集中记在 `00-absorption-plan.md` 第二节。
