# handoff —— 对外交付稿（给别的 PPT 工具 / agent 用）

本目录放**可以拿出去打磨的自包含交付稿**，与 `vN/`（本仓库自己的 PPTX 生产线）不是一回事。

| 文件 | 说明 |
|---|---|
| `AI-Coding-演变指南-全页内容-v3.3.md` | ★ **全场 42 张的全部页面内容**，自包含：每页的页号、上屏文字（L1–L4）、这一页在答哪一步、讲法、推导句、证据与口径。**不依赖本仓库任何其他文件。** |

## 为什么有这个目录

本仓库原来的生产线是「Python 生成器 → `.slide` DSL → `slidep` 编译成 PPTX」。
那条路在 v0.4 暴露出问题较多，改为**把内容抽成一份自包含 Markdown，拿到外部工具里重新做版式**。
所以本目录的产物是**内容事实源**，不是版式成品。

## 使用方式

- **按 `^---$` 切分**即可得到每一页：第 1 段是说明与附录，第 2 段起依次是 42 页
  （P1, P2, P3, B1, P4, …, P37）。**`---` 只出现在页面边界上。**
- 标了**「不上屏」**的字段是给讲者 / 给你理解用的，**不要放上页面**。
- 页面按**实际放映顺序**排列，停顿页（B1–B5）就插在它该出现的位置。
