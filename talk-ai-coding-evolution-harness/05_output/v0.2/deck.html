Loop 管时间上的反馈

loop {
  act()        # 触发
  verify()     # 验证
  if !pass: retry()   # 停止条件
  remember()   # 记忆
}
没有门禁的 loop，只会更快地放大错误
—四要素：触发 · 验证 · 停止条件 · 记忆
—黄金法则：上次结果不改变下次行动，那叫重试，不叫 loop
—反转：没有门禁的 loop，只会更快地放大错误

P36★ Pi 的代价 · 2 min第四幕 · 两个进展

Pi 把信任放在“谁装了它”，而不是“它是什么代码”上

结构做对的

  • 三层接缝按变化轴裁接口
  • 统一注入点
  • 进程内护栏：失败即拦

没护栏的

  • 没有默认沙箱——扩展 = 宿主进程同等权限
  • 装一个陌生包 ≈ 执行它的任意代码
  • 也没有 MCP / ACP：外部工具付适配层税
  • 也没有扩展 API 版本契约：升级后可能静默失效
—口径：不是说它不安全，是说护栏要你自己补
