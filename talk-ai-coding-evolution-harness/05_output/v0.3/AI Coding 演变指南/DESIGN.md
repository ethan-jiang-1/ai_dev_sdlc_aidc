# DESIGN.md — AI Coding 演变指南：从 Prompt 到 Harness

> 本项目走**通用设计原则**（技术分享场景，不命中 academic / consulting / redgold 任一预设风格）。
> **设计宪法优先级**：用户已锁定的视觉方向 ≻ 通用设计原则缺省值。凡覆盖缺省值之处，本文均显式标注 `【override】`。

---

## 0. 本项目的视觉判断（一句话）

上一版的问题是**所有元素都趋近中间大小**——标题 27px、正文 13.5px、无巨型锚点、大量 50:50 等分。
本版的三条硬修正：**① 字号阶梯拉开（正文 22px / 主标题 36px / 巨型锚点 120px）；
② 每页必有一个视觉锚点；③ 除 2 页外全部走非对称版式。**

---

## 1. 画布与全局母版

画布 **1280 × 720**（16:9）。所有内容页共用三区母版，页面内**每页复用同一组 px 值**。

| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| 页面 padding | 上 28 / 下 24 / 左右 64 | — | 安全区，禁止用绝对定位绕过 |
| **A · 标题块** | y 28–124 | 96px | 眉题（14px mono，墨 40%）+ 主标题（36px bold，行高 1.25） |
| **B · 内容区** | y 124–656 | **532px 可用** | 一切正文、图表、结构图、卡片 |
| **C · 页脚条** | y 656–696 | 40px | 左：`AI CODING EVOLUTION`（14px mono，墨 35%）／右：`NN / 49`（14px mono，墨 45%） |

**高度计算式**（每页动笔前核对）：
`28(上padding) + 96(A区) + 532(B区) + 40(C区) + 24(下padding) = 720` ✅

- 封面 / 转场页 / 结束页 / 停顿页（共 12 页）**允许省略 C 区**，走自定义版式（大字居中 + 大留白）。
- **停顿页 I1–I4 不显示页码**（C 区只保留左侧眉题）。
- 标题位置、页码位置在 37 个内容页之间**严格一致**，禁止逐页随机发挥。

## 2. 颜色系统

### 2.1 色彩池（4 个 hex + 画布，画布单列不计入池）

| 角色 | hex | 用途 | 面积占比 |
| :--- | :--- | :--- | :--- |
| **画布** | `#FAFAF7` | 全篇统一底色（纸白） | 铺满 |
| **主色** | `#1C1F23` | 标题、正文主文本、结构线、图表主轴 | ≤ 55% |
| **辅色** | `#0F6E56` | active path / 反馈 / 正面锚点 / 巨型数字 | ≤ 25% |
| **强调色 A** | `#A32D2D` | 门禁 / 风险 / 缺口 / 未护栏处 | ≤ 8% |
| **强调色 B** | `#8A5A00` | 证据 / 提示 / 已提交工件 / 趋势级标注 | ≤ 8% |
| 中性（由主色半透明派生） | `rgba(28,31,35,0.04 / 0.10 / 0.18 / 0.40)` | 卡片底、分隔线、次级文字 | 剩余 |

**派生规则**：浅色底一律由主色 rgba 派生，**不引入新的 hex**。

### 2.2 色彩节奏（每页必须落在下表模式之一，禁止全篇雷同）

| 模式 | 适用 | 强调色占比 |
| :--- | :--- | :--- |
| **A · 克制** | 常规内容页（valley） | 强调色 ≤ 5%，辅色 ≤ 10% |
| **B · 聚焦** | Hero 页（peak） | 强调色 15–20%，只出现在锚点元素上 |
| **C · 留白** | 转场 / 停顿 / 结束 | 强调色 ≤ 3%，几乎只有墨色 |

全篇 **Hero 10 页走 B**、转场与停顿 9 页走 C、其余 30 页走 A。

### 2.3 渐变与半透明

- **【override】本项目禁用渐变与投影**——用户已锁定的视觉方向是"纸白 + 平色"，
  层级只靠 **① rgba 半透明层次 ② 1px 结构线 ③ 尺度对比** 三件事建立。
  这条覆盖通用原则 §2.2 的"允许且鼓励渐变"。
- **允许并鼓励半透明**：卡片底 `rgba(28,31,35,0.035)`；证据横幅底 `rgba(138,90,0,0.07)`；
  风险块底 `rgba(163,45,45,0.06)`；元素叠压时底层 `opacity: 0.18`。

### 2.4 禁忌

- 同一页出现 ≥ 2 套主色板
- 青绿与朱红同页都做大面积（只允许一个当焦点，另一个降为 1px 线或小圆点）
- 全篇每页颜色分配比例差异 < 10%
- **Emoji 一律禁用**（原稿里的 ⚠️ 全部换成 `FAIcon name='exclamation-circle'`）

## 3. 字体系统

### 3.1 字体家族（**2 套**）

| 用途 | 字体 | 说明 |
| :--- | :--- | :--- |
| 中文全部 | **`PingFang SC`** | macOS 内置，商务现代（推荐表"sans"行） |
| 西文 / 数字 / 代码 / 眉题 / 页码 / 指标 | **`SF Mono`**（回退 `Menlo`） | 承担"代码终端母题"——这是本项目最核心的视觉识别 |

> 不用第三套字体。西文正文也走 mono，**刻意强化终端母题**；中文永远走 PingFang SC。
> 【override】通用原则称"禁止只用系统默认无衬线"——本文已指定具体字体名，满足其意图。

### 3.2 字号层级表（每页只能出现下列值）

| 层级 | 字号 | 字重 | 行高 | 字距 | 用途 |
| :--- | ---: | :--- | ---: | :--- | :--- |
| 封面主标题 | **76** | 600 | 1.18 | -0.5 | 仅 P1 |
| 转场大字 | **64** | 500 | 1.35 | 0 | P13 / P23 / P43 / P44 + I1–I4 |
| **巨型锚点** | **120** | 700 | 1.0 | -2 | P5 / P25 的核心数字 |
| 次级巨型锚点 | **88** | 700 | 1.0 | -1 | P2 对照大字 / P26 / P37 |
| 页面主标题 | **36** | 600 | 1.25 | 0 | 全部内容页 A 区 |
| 卡片小标题 | **24** | 600 | 1.4 | 0 | 卡片头 / 分区头 |
| 正文 | **22** | 400 | 1.55 | 0 | L3 支撑、卡片正文 |
| 辅助文本 | **18** | 400 | 1.6 | 0 | 注释、次要说明、表内文字 |
| 眉题 / 页码 / 脚注 | **14** | 400 | 1.4 | 0.5 | mono，全篇位置固定 |

**关键规则**：巨型锚点（120/88）与正文（22）之间必须存在 **≥ 4 倍**的字号落差——
这是本项目解决"看起来一般"的核心手段。

## 4. 信息密度门禁

**【override】本项目声明为「留白型」keynote**（讲稿承担论证，上屏只放结论），因此覆盖 §4 默认值：

| 页面类型 | 正文字数下限 | 主视觉占 B 区 | 留白上限 |
| :--- | ---: | ---: | ---: |
| 内容页 · 单主题 | **≥ 120**（默认 180） | ≥ 30% | **≤ 45%**（默认 35%） |
| 内容页 · 卡片组 | 每卡 ≥ 70（默认 100） | — | ≤ 45% |
| 数据 / 图表页 | ≥ 80 | ≥ 50% | ≤ 40% |
| 转场 / 停顿页 | ≥ 10 | — | 不限（50–75%） |
| 封面 / 结束页 | ≥ 20 | ≥ 35% | 不限 |

### 4.1 视觉锚点（每页强制 ≥ 1 个）

满足**任一**即算锚点：
- 字号 ≥ **64px** 的文字元素，或
- 占 B 区面积 ≥ **40%** 的结构图 / 图表，或
- 面积 ≥ **280×200** 的平色块（含 rgba 层）

**禁止**：一页里所有元素都落在 18–36px 这个区间——这正是上一版失败的原因。

### 4.2 容器填充率

- 卡片内容垂直占用 ≥ 容器高度 **85%**
- 卡片尾部元素（标签条 / 结论条）用 `marginTop: 'auto'` 钉到容器底部
- 同一行兄弟卡片的"标题块 / 正文块 / 尾部元素"三段**必须 y 轴等高**

### 4.3 留白策略

- 焦点元素周围留 ≥ **40px** 呼吸空间
- **禁止"均匀稀薄"**：留白必须围绕焦点，不是每两个元素之间都差不多
- Hero 页留白可达 40–50%，且必须围绕锚点集中

## 5. 视觉元素系统

### 5.1 本 deck 不使用照片 / AI 生图

**【override】**用户已锁定"全原生矢量"。所有视觉元素属于通用原则 §5 明确允许 SVG 的类别：
**架构图 / 关系网络 / 时间轴 / 矩阵 / 巨型数字 / 趋势箭头 / 抽象几何概念**。

实现路径按优先级：**① `<Box>` + `<Text>` 绝对定位（首选，占 80%）→ ② 内联 `<svg>`（曲线与连线。
占 20%）**。**不使用 `<Diagram>`**（依赖远程服务，不稳定）。

### 5.2 分级与最小尺寸

| 等级 | 本项目形态 | 最小尺寸 / 占比 | 出现位置 |
| :--- | :--- | :--- | :--- |
| **L1 · 主视觉** | 中心环绕图 / 五层叠加带 / 门禁序列 / DAG / 扇出图 / 时间线 / 巨型数字 | B 区 ≥ 40%，或 ≥ 280×200 | 10 个 Hero 页 + 12 个结构图页 |
| **L2 · 支撑图** | 两列对照 / 三栏结构 / 编号清单 / 自查表 / 代码块 | ≥ 280×180 | 其余内容页 |
| **L3 · 母版元素** | 页脚左侧 `AI CODING EVOLUTION`（mono 文本，非图形）+ 1px 顶部分隔线 | 全篇位置一致 | 全部内容页 C 区 |

**严禁**：把结构图缩成 200×70 塞进标题块右侧；L3 位置逐页漂移。

### 5.3 图标（克制使用）

统一 **Font Awesome 线性（line）风格**，尺寸统一 **32×32**，着色只用辅色或强调色。
全篇最多使用 6 处——只用在三个动词上：
`shield`（圈住）／`check-circle`（拦住）／`eye`（看清）／`exclamation-circle`（证据强度提示）。
**严禁编造图标名，严禁 Emoji。**
