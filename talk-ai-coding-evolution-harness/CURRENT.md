## 当前定调（v3.1，未经变更不得漂移）

1. **全场主轴**：**这次改动，凭什么可以上线？** 听众的流程本来就在答这题——谁批 / 在哪个环境跑 / 留下什么记录。
2. **组织原则**：按**听众要解决什么**分幕，不是按素材有什么分幕。每一幕是这个问题的一步推导。
3. **五层工程** = 同一个问题的五轮答案。每层讲清：答案放在哪 / 默认了什么前提 / 这个前提什么时候不成立。
   **不要讲成"五个新名词"；量词只用"层"，不说"五门工程"。**
4. **命名时序**：harness 在 P7 给名（动机已在 P5 / P6 建立）；`Agent = Model + Harness` 在 P11 才给。
5. **终点**：你今后要写两类程序——**传统程序**（现成 harness 够用，**这条路不用自己造**）
   与**智能体**（写可以在现成工具里写，**跑**需要一个 harness 环境）→ **那一圈得在你自己手上**。
6. **第四幕**：DSH **充分展开**三页（无特权核心 / 会话日志 / 代价）；自建那条路**简单介绍**；
   Pi 退为"能轻到什么程度"的样本；P33「两边都还没解决」不能省。
7. **节奏**：**6 张呼吸页 + 3 处收束页短停 = 9 次呼吸**。呼吸页只放两处：结构接缝 / 段内超 10 分钟；
   每张必须**同时收上一段、启下一段**。收束页（P11 / P24 / P33）自带呼吸，不重复插页。
   **检查点 ≠ 悬念**——"另一条呢？"禁用，"你已经知道 A 不行、B 不行，那 C 呢？"可用。
8. **语域**：教学 / 推导，不是市场营销。句类用前提 / 推导 / 结论 / 边界。
   大字只能是论点本身且底下压着对照项（全文仅 P20 / P21 用 104）；讲者分钟数全部下屏。
9. 三铁律不变：**无 OPC / 一人公司 / 姊妹项目引用**；**不点行业名、不用行业专属术语**；
   **不讲成合规培训**。证据四档标注不变。
10. **版本单一**（本轮新增）：每类产物目录里只留当前版本，旧版本移出到
    `.tmp-harness-talk-archive-YYYYMMDD/`。**不允许新版在下、旧版在旁。**
