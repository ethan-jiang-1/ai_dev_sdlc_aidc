# Harness 里头干啥 · 抓要害的讲法

> 第二幕的核心讲法。目的：让听众用一句话记住 harness 到底在干什么，并且**能对号入座**。
> 源：Böckeler 的 Guides / Sensors 框架（`../_reference/rawdata_ai-coding-evolution-final/final_v4/03-2026-harness-era.md`）。

## 一句话

**模型给能力，harness 给可靠性。**
harness = 模型之外的一切；它干的事是**把一个"很强的模型"变成一个"可靠的交付"**。

## 两套控制

- **Guides（前馈）**：在 agent 行动**前**约束它——按这个样式写、必须过这个 lint、只能用这些工具。
- **Sensors（反馈）**：在 agent 行动**后**把结果喂回——测试挂了、类型不过、exit code 非零。
- 各分两档：
  - **computational（确定性）**：测试 / lint / 类型 / schema——可复现、可审计。
  - **inferential（概率性）**：AI review / LLM-as-judge——不可审计。
- **原则：能交给确定性的，绝不靠概率性的。** 确定性优先，模型判断只做兜底。

## 三个动词（抓要害）

1. **圈住（bound）**——沙箱 + 权限。只能碰该碰的文件、连该连的网、做被授权的操作。
   子项：文件系统与网络的隔离、权限模型（什么能做、什么先问）。
2. **拦住（gate）**——工具协议 + 验证门禁。把"对错"变成机器可判的关卡，
   在错误离源头最近的地方就地拦下。授权要点：**authorize at execution, not at generation**。
3. **看清（see）**——可观测性 + provenance + CI。trace / metrics / logs 记下每一步；
   provenance 记下产物"谁造的、从哪来"；接进 CI 让每次交付可审计。

## 团队映射（本 talk 新增，第二幕的关键落点）

这一层不要讲成"技术组件清单"，讲成**"你们已经在做的事，只是还没套到 agent 上"**：

| 团队已有的纪律 | harness 动词 | 要补的一步 |
|---|---|---|
| 生产不是谁都能碰、环境隔离 | 圈住 | 把 agent 圈进同一圈边界（沙箱、权限） |
| 变更要审批、要有人复核 | 拦住 | 让 agent 的动作过同一道门禁，不靠它自觉 |
| 操作要留痕、出事能还原 | 看清 | 把 agent 每一步写进那份日志（trace、provenance） |

**讲法要点**：
- 左列是听众**已经相信**的东西，先让他们点头，再往右推——阻力最小。
- 中间是 harness 的三个动词，是这场要教的新词，但只有三个，量很小。
- 右列是"要补的那一步"，也是**团队版独有的痛点**：人对人的纪律已经有了，对 agent 的还没有。
- **防线**：这一页不能滑向治理 / 合规培训。讲完立刻拉回"所以 harness 决定交付底线"。

## 六个构件（落到"装了什么"）

| 构件 | 干什么 | 归到 |
|---|---|---|
| 沙箱 | 文件 + 网络隔离 | 圈住 |
| 权限模型 | 什么能做、什么先问；**执行时授权** | 圈住 |
| 工具协议 | 模型能调什么工具、怎么执行、结果回哪 | 拦住 |
| 验证门禁 | 测试 / lint / 类型 / schema，尽量确定性 | 拦住 |
| 可观测性 | trace / metrics / logs 还原 agent 决策 | 看清 |
| provenance + CI | 产物可追溯、交付可审计 | 看清 |

## 提议权与执行权

- **提议**：模型 / Loop / Graph 给出下一步动作。
- **检查**：权限 + 确定性门禁**独立**判断。
- **执行**：放行 / 拒绝，并留下记录。

**提议权可以交给模型；执行权必须留在 harness。**
对团队的讲法：**审批不能挂在"它说它会怎么干"上。**

## 反面证据（2026 授权事故）

因果链，不点名、不堆编号：

1. 工具调用的形状可以被伪造或绕过模型回合。
2. 如果执行端只相信"这看起来像一次合法模型调用"，独立授权就缺失了。
3. 动作仍然会发生。
4. 修复口径：**`authorize at execution, not at generation`**。

## 为什么这一层最关键（承接第三幕）

- Loop 每次迭代实例化一个 harness；Graph 的每个节点跑在自己的 harness 里。
- 三层本质是同一件事：**用反馈 + 确定性约束模型，换可靠结果**。
  harness 给单次反馈；loop 把它连成循环；graph 把它编排起来。
- 2026 的安全事件集中爆发在这一层——因为"可靠性"住在这里，风险也住在这里。
- **本 talk 的升级**：可靠性只解释"为什么不翻车"，不解释"为什么更强"——
  后者才是第三幕要证明的，也是"harness 是变量"的立论基础。
