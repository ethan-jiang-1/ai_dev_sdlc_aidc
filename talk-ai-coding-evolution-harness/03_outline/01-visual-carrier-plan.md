# 页面承载规划（v1）

> 解决的问题：`04_drafts/ppt-text-v1.md` 只有"上屏一两行 + 讲点"，那是**讲稿骨架**，
> 不是页面。45 页 / 84 分钟，平均每页要撑近 2 分钟——**页面必须有承载**。
> 本文件定义每页放什么、放多少，作为 PPT 生产时的版式依据。

## 一、每页的四层承载（页面解剖）

| 层 | 内容 | 规格 |
|---|---|---|
| **L1 结论标题** | 一句话，就是这页的结论 | 19–24px，500 字重，左对齐，紧贴页面上沿 |
| **L2 主视觉载体** | 结构图 / 对照表 / 数据带 / 代码块 / 清单 | **占内容区 ≥ 40% 面积**，是页面的重心 |
| **L3 支撑信息** | 2–4 条标注或要点，与 L2 咬合 | 12–13px；**不与 L2 重复** |
| **L4 页脚** | 来源 + 证据强度 + 页码 | mono 11px，灰；证据强度必须与数字同屏 |

**判定标准**：任何一页，如果抽掉标题只剩一两行字，那页就是空的——必须回炉。

## 二、载体类型库

| 代号 | 载体 | 用在什么页 | 密度下限 |
|---|---|---|---|
| **A** | 结构图（关系 / 流动 / 分层 / 环绕） | 机制页、因果页 | ≥ 6 个图元 + 3 条标注 |
| **B** | 对照表（两列或多列） | 比较页、取舍页 | ≥ 5 行 × 2 列，表头独立色块 |
| **C** | 数据带（对比条 / 大数字 / 指标卡） | 证据页、结论页 | ≥ 1 个视觉锚点，长度 ≥ 88px |
| **D** | 终端构件（终端块、命令、日志行、diff、exit code） | **母题层**，极少单独成页 | 与 A/B/C/E 混排 |
| **E** | 清单（编号 / 勾选 / 自查项） | 方法论页、判断页 | ≥ 3 项，项间有真实差别 |
| **T** | 转场页（单句大字 + 大留白） | 幕间呼吸 | **全场限 5 页** |
| **F** | 封面 / 收尾 | 首尾 | 2 页 |

**D 是母题不是版式**：终端构件贯穿全场（眉题、页码、口径脚注、代码块、日志行），
但只有确实要展示"一段真实的东西"时才单独成页。

## 四、密度自检（进 PPT 生产前逐页过）

- [ ] L2 主视觉占内容区 ≥ 40%；抽掉标题后页面**不空**
- [ ] L3 支撑信息与 L2 不重复，且 ≥ 2 条
- [ ] 结构图页 ≥ 6 个图元；对照表页 ≥ 5 行；数据页有 ≥ 88px 的视觉锚点
- [ ] 连续两页不使用同一版式结构（避免"十页一模一样的卡片"）
- [ ] 每页有且只有一个结论；结论与证据同屏
- [ ] 证据强度标注与数字同屏（P25、P26 是重点）
- [ ] 终端母题（D）全场一致：眉题、页码、口径脚注用同一套 mono 规格

## 五、由本规划反推的两处修订

1. **`04_drafts/ppt-text-v1.md` 的讲点必须扩写。** 现在每页讲点 1–2 句，
   撑不起 2 分钟。目标：每页讲点 **150–250 字**，含一个具体例子或听众场景。→ 落在 v2。
2. **上屏文字按"四层承载"重排。** v1 的上屏是"标题 + 要点"的平铺；
   v2 要按 L1/L3 分工：标题即结论，要点只放与主视觉咬合的那几条。
