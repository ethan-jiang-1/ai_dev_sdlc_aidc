# 页面承载规格（版式依据）

> 解决的问题：页面不是"标题 + 要点"，**抽掉标题后页面不能是空的**。
> 36 页 / 约 79 分钟，平均每页要撑 2 分钟以上——**页面必须有承载**。
> 本文件定义**承载的分层与载体类型**，作为 PPT 生产时的版式依据。

## 一、每页的四层承载（页面解剖）

| 层 | 内容 | 规格 |
|---|---|---|
| **L1 结论标题** | 一句话，就是这页的结论 | 19–24px，500 字重，左对齐，紧贴页面上沿 |
| **L2 主视觉载体** | 结构图 / 对照表 / 数据带 / 代码块 / 清单 | **占内容区 ≥ 40% 面积**，是页面的重心 |
| **L3 支撑信息** | 2–4 条标注或要点，与 L2 咬合 | 12–13px；**不与 L2 重复** |
| **L4 页脚** | 来源 + 证据强度 + 页码 | mono 11px，灰；证据强度必须与数字同屏 |

**判定标准**：任何一页，如果抽掉标题只剩一两行字，那页就是空的——必须回炉。

## 二、载体类型库

| 代号 | 载体 | 用在什么页 | 密度下限 |
|---|---|---|---|
| **A** | 结构图（关系 / 流动 / 分层 / 环绕） | 机制页、因果页 | ≥ 6 个图元 + 3 条标注 |
| **B** | 对照表（两列或多列） | 比较页、取舍页 | ≥ 5 行 × 2 列，表头独立色块 |
| **C** | 数据带（对比条 / 大数字 / 指标卡） | 证据页、结论页 | ≥ 1 个视觉锚点，长度 ≥ 88px |
| **D** | 终端构件（终端块、命令、日志行、diff、exit code） | **母题层**，极少单独成页 | 与 A/B/C/E 混排 |
| **E** | 清单（编号 / 勾选 / 自查项） | 方法论页、判断页 | ≥ 3 项，项间有真实差别 |
| **T** | 转场页（单句大字 + 大留白） | 幕边界 | **全场限 5 页** |
| **P** | **呼吸页**（单句大字 + 留白 ≥60% + **不编页码**） | **结构接缝处的承接**，不占正文编号 | **全场 6 张（B1–B6）** |
| **F** | 封面 / 收尾 | 首尾 | 2 页 |

**T 与 P 的区别（不要混）**：**T 在幕边界**，是"这一幕结束了"；**P 在密集块内部**，
是"这一块讲完了，你先把它消化掉"。T 有结论、要承接下一幕；P **只复述刚讲完的那一句**，
不引入任何新信息。P 的密度下限反过来——**留白越多越好**。

**D 是母题不是版式**：终端构件贯穿全场（眉题、页码、口径脚注、代码块、日志行），
但只有确实要展示"一段真实的东西"时才单独成页。


> **本文件只管版式规格。**
> **逐页用哪个载体，不在这里维护**——36 页的逐页承载写在
> `../04_drafts/ppt-text-v3.md` 每页的 **L2 主视觉**字段里，一处维护。

## 三、密度自检（进 PPT 生产前逐页过）

- [ ] L2 主视觉占内容区 ≥ 40%；抽掉标题后页面**不空**
- [ ] L3 支撑信息与 L2 不重复，且 ≥ 2 条
- [ ] 结构图页 ≥ 6 个图元；对照表页 ≥ 5 行；数据页有 ≥ 88px 的视觉锚点
- [ ] 连续两页不使用同一版式结构（避免"十页一模一样的卡片"）
      **收紧为**：同载体连续不得超过 **3 页**（呼吸页不计入连续），且相邻两页的**图元形态必须不同**
      （环形 / 横向序列 / 时间线 / 三段推进 / 因果链算不同形态）。
      **样板**：P18–P20 是三个动词页、都是 A，靠"一环边界 → 门禁序列 → 时间线"三种形态区分，
      同载体连续不得超过 3 页这条同样适用于呼吸页的间隔判定。
- [ ] 每页有且只有一个结论；结论与证据同屏
- [ ] 证据强度标注与数字同屏（P20 / P21 是重点——必须当场降档）
- [ ] 终端母题（D）全场一致：眉题、页码、口径脚注用同一套 mono 规格
- [ ] **呼吸页 B1–B6 走反向标准**：留白 ≥60%、只有一句大字、**不显示页码**、不用语义色
      （正文页求"抽掉标题后不空"，呼吸页求"越空越好"——两套标准，别互相套用）
