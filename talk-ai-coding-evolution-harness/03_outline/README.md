## 为什么合并掉了逐幕内容文件

早期规划里有 `01-opening-and-act1-content.md` 等五个逐幕文件，与 `04_drafts/ppt-text-vN.md`
的内容高度重叠：都在写"这页说什么、讲什么"。两处维护会立刻产生不一致。
因此改为：**页面职责留在本目录，页面文字与讲点只写一处（`04_drafts/`）**。

## 约束

1. **一页一个叙事任务**；标题即结论，不写"XX 概述"这类关键词式标题。
2. **★ 尾巴区间（P24–P45）是全场赌注所在**，任何页面增删先动引桥（P1–P23），不动尾巴。
3. 前 23 页总时长不得超过 **42 分钟**，否则尾巴被压缩。
4. 外部数字必须与证据强度标注同屏。
5. 上屏文字短于讲点句——讲点在 `04_drafts/`，是完整判断；上屏只承载最硬的那半句。
6. **第四幕两条路线平权**：DSH 三页、Pi 三页，中间必须有 P37「两边都还没解决的那件事」。
