## 为什么没有逐幕内容文件

早期规划里有 `01-opening-and-act1-content.md` 等五个逐幕文件，与 `04_drafts/ppt-text-vN.md`
的内容高度重叠：都在写"这页说什么、讲什么"。两处维护会立刻产生不一致。
因此改为：**页面职责留在本目录，页面文字与讲点只写一处（`04_drafts/`）**。

## 约束（v3 口径，覆盖 v2）

1. **一页一个叙事任务**。L1 写**这一页在答哪一步**，不写"这一页的结论"，也不写"XX 概述"。
2. **尾巴（第三幕 → 收尾，P20–P37，18 页 / 约 36.5 min）是全场赌注**，
   任何页面增删先动引桥（P1–P18），不动尾巴。
3. **停顿页只放两处**：结构接缝，或同一条线连讲超过 10 分钟。共 5 张（B1–B5），
   每张必须**同时收上一段、启下一段**；只复述上一页的不设。
   收束页（P12 / P25 / P34）自带停顿，不再重复插页。
4. 外部数字必须与证据强度标注**同屏**；P20 / P21 必须当场降档。
5. 上屏文字短于讲点句——讲点在 `04_drafts/`，是完整判断；上屏只承载最硬的那半句。
6. **第四幕不是产品推荐**：DSH 充分展开三页（无特权核心 / 会话日志 / 代价），
   自建那条路简单介绍，Pi 退为"能轻到什么程度"的样本，P33「两边都还没解决」不能省。
7. **零增量页不留位**：听众拿不到东西的页，删或合并。
