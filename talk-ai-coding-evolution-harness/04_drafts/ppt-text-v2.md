## P5 · 发动机
**L1** 模型越强，工程杠杆点越往上移
**L2** A — 三段因果链，向右推进
**L3**
- 模型能力更强 →
- 单次交互的边际工程收益更低 →
- 工程杠杆点上移
- 每往上一层，都是**对下面一层做了一个假设**
- 底部：**上移不等于替代**——五层是叠加，不是在旧层上盖新层
**讲法**（不上屏）"假设"那条是本页最锋利的一句，四条假设要能当场说出来：
Prompt→Context 假设"**模型能吃上下文**"（所以别再往 prompt 里塞事实）；
Context→Harness 假设"**环境是受控的**"（所以别再往 context 里写规矩）；

**每一层的假设在极限处都会失效**——这句是 P13"问题落回中间那层"的伏笔，也是全场的第一颗种子。

## P6 · Prompt
**L1** Prompt 管表达 —— 但它已经不再是你的杠杆
**L2** B — 两列对照：两年前 / 现在
**L3**
- 两年前：三小时调措辞，效果立竿见影；模板、few-shot、角色设定各有讲究
- 现在：调不调，差别已经不大了
- 结论一句：**不是你变强了，是这层被吃掉了**
- 但那套东西没有白学——它变成了默认值，只是不再是你的杠杆
**讲法**（不上屏）先认账再换地方：你们当年学的 prompt 技巧全都还有用，只是模型把它吃成了默认能力。这一页不是宣布"你们白学了"，是说**力气该换地方**。否则听众会带着被否定的情绪听后面 40 分钟。
**被追问时的兜底**（不上屏）引原文：Anthropic 官方工程博客（2025-09-29）原句是
"the exact formatting of prompts is likely becoming less important as models become more capable"——
**是定性判断，不是量化结论**，不要说成"效率掉了百分之多少"。
另可补一句：同一体系 2026 年那篇讲 prompt 缓存的文章说明 prompt 基本功在 harness 时代仍然有效——
这正好印证"没白学，只是换了位置"。
**L4** 一手（Anthropic 官方工程博客 2025-09-29）· 原文为**定性判断**，非量化 · 6 / 45

## P7 · Context
**L1** Context 管模型此刻所见 —— 不是越多越好
**L2** A — 上下文窗口示意，中段标出塌陷区
**L3**
- 塞得越满，越可能看漏中间那一段
- **更多 context ≠ 更好回忆**
- 最小脚手架也能跑出结果：一个 prompt、一个 Bash、一个 Edit
- 反常识：最好的 context 工程，往往是"少放"
**讲法**（不上屏）"最小脚手架"那句有**一字不差的一手原文**可引：
Anthropic 公布 SWE-bench Verified 49% 时写的是 "keep the scaffolding minimal.
**The agent has a prompt, a Bash Tool, and an Edit Tool.**"（2024-10-30）——
上屏一句话，被追问就引原句。

**L4** 一手：Anthropic 工程博客 2025-09-29（命名 context rot）｜独立量化：Chroma《Context Rot》2025-07（⚠️ 厂商自建评测）｜最小脚手架：Anthropic SWE-bench Verified 公告 2024-10-30 · 7 / 45

## P15 · 一句话
**L1** 模型给能力，harness 给可靠性
**L2** B — 两列：模型给的 / harness 给的
**L3**
- 模型给的：能力上限 · 语言理解 · 代码生成
- harness 给的：权限清楚 / 环境隔离 / 工具受控 / 结果可验 / 过程可追 / 失败即停
- 收束：它不负责让模型变聪明，它负责**让同一个模型每次都不掉链子**
**讲法**（不上屏）本页 L1 是全场最需要被记住的一句，**它有一手原句做底**：
Böckeler 写的是 `Reliability is a property of the model-plus-harness system`——
"可靠性是模型＋harness 这个系统的属性"。被追问出处就报这一句，不用绕回报告。
**L4** 一手（Böckeler《Harness engineering for coding agent users》，memo 2026-02-17 / 全文 2026-04-02，martinfowler.com）；L1 中文为本 talk 转写 · 15 / 45

## P19 · 拦住

## P24 ★ · 命题
**L1** 同一个模型，换一圈 harness，就是两套交付系统
**L2** A — 左右两套系统对照（同一模型块，两圈不同厚度的边界）
**L3**
- 左：同一个模型 + 一圈薄边界 → 交付靠**个人**
- 右：同一个模型 + 一圈厚边界 → 交付靠**系统**
- 差的那圈不是模型，是**谁放行、碰得到什么、留下什么记录**
**讲法**（不上屏）承接 P23：从这页起换一个角度问同一个问题——前面讲的是"不翻车"，这里开始讲"能做成什么"。P12 说过"十个人十套配置"，**本页只用一句回指，不要重讲那个画面**（本页的画面是"两个团队、三个月后"）。
**被追问"你凭什么下这个判断"时的兜底**（不上屏）两条：
① **这不是新发现**——SWE-bench Verified 49%（Claude 3.5 Sonnet，2024-10-30）那会儿，
"around the same model"只优化外面的脚手架就已经改变了成绩；Codex 只是把这个效应放大到将近三倍。
② 本场的这一条是**我的判断**，我只敢说"同一个模型换一圈 harness 会是两套交付系统"，
不敢说"换 harness 一定更好"——好不好取决于换的是什么。
**L4** 本场核心判断（A6）｜历史旁证：Anthropic SWE-bench Verified 公告 2024-10-30 · 24 / 45

- 判据：**可复现、有方法论，才能当基准；否则只能当信号**。这道门槛比看上去高——ICSE 2026 有篇论文发现，**连榜单分数本身都可能掺着记忆**（同一批题 76%，换成没见过的仓库只剩 53%）
- 诚实交代：本幕三条证据**没有一条够格当基准**——我的结论靠的是它们**指向同一个方向**，不是其中任何一个数字
**讲法**（不上屏）这一页是全场"证据纪律"的示范动作，关键在**当面承认那条快讯对我们有利**——
正因为它对我们有利，才更要打折。这个动作本身就在建立可信度，比多给一个数字管用。
**最后那条"诚实交代"不要省**：一个敏锐的听众会立刻发现"你三条证据没一条能用"，
**与其被问，不如自己先说**——这句话说完，"harness 是变量"这个判断反而更站得住。
那个学术发现**只讲 76 / 53 两个数**，不展开论文细节；它在这里的作用是说明"基准的门槛比你想的高"，不是讲学术。
**L4** ⚠️ 趋势级（快讯 · **标题级捕获** · 无方法论）｜判据旁证：arXiv 2506.12286（ICSE 2026 SEIP，学术）｜结论方向由 A6 认领 · 26 / 45
