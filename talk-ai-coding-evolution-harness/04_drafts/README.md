## 两类文件的分工

| 文件 | 管什么 | 目标长度 |
|---|---|---|
| `ppt-text-vN.md` | **页面**：四层承载、上屏文字、页脚来源与证据强度 | 每页 L3 2–5 条 |
| `talk-vN.md` | **口语讲稿**：逐页怎么讲 | **每页字数 ≈ 时长 × 220 × 0.8**（D23），全场约 14,700 字 |

**不要混**：页面求"抽掉标题后不空"；讲稿求"能连着说两分钟不卡"。

## 规则

1. **必须通过中文编辑门**（见 `../AGENTS.md`）：先确定要说清的判断，再用中文原生句法组织；
   逐页朗读，凡是需要倒回去才能读懂、或离开英文词就说不清的句子，继续改写。
2. **上屏文字短于讲点句**。讲点是完整判断，上屏只承载它最硬的那半句。
3. 每页必须能回答：这页的结论是什么、证据是哪一条、证据强度是哪一档。
4. **证据强度四档标注**（一手 / ⚠️ 厂商自述 / ⚠️ 降级取证 / 趋势级）必须与数字同屏。
5. 一旦成稿被确认，它就是**生产事实**；页面职责、口径、故事线的后续变更都要以它为起点反向同步。
6. 改稿时**先改本目录**，再按 `03_outline → 02_evidence → 01_storyline` 反向同步，不让旧提纲复活。
